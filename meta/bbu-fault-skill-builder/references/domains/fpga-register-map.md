# ITRAN 单板 FPGA 寄存器速查（单板域：ITRAN）

> 由 ITRAN FPGA 寄存器表（精简版）整理沉淀，供 AI 在 ITRAN 单板故障分析中解释寄存器值、定位告警与主备/时钟异常。
> **单板域约定**：寄存器地址、位定义、PLL 器件（80227）、主备状态编码均为 ITRAN 特有；其它单板（如 VSWe）不一定相同，不得跨单板套用。新单板需访谈确认后另立域。

## 1. 地址空间总览

| 模块 | 功能 | 起始 | 结束 | 位宽 |
|---|---|---|---|---|
| 主控 | 通用寄存器 / 模拟面板UART / 模拟多路I2C / 器件配置状态接口 | 0x0000 | 0x13ff | 16bit |
| SFP && QSFP | SFP QSFP 控制 | 0x1400 | 0x1fff | 16bit |
| IPMI 总线 | IPMI 接口 | 0x2000 | 0x3fff | 16bit |
| 时钟同步 | 参考源及鉴相 / 时钟下发 / 单板及时钟主备 | 0x4000 | 0x7fff | 16bit |
| 1588 | phy 同步 / sw 同步 | 0x8000 | 0xbfff | 16bit |
| 告警及检测 | 通用告警模块 / 通用检测模块 | 0xc000 | 0xefff | 16bit |

- 主控区地址为**偏移地址**，绝对地址 = `0x0000_0000 + 偏移`；时钟同步区从 0x4000 基址起算。
- `N` = 板位/通道号占位符（0/1…）；`0xcxxN` 基址 0xc000、`0xd0xx` 基址 0xd000。
- 读写：`R/W`=可读可写、`R`=只读；bit 编号 0 起算；复位值默认 0，非 0 见描述。

## 2. 故障排查关键寄存器（速查）

完整逐寄存器位定义见 `assets/shared/clk-field-dictionary.yaml` 的 `ITRAN_FPGA_REG` 段。以下按排查链摘录要点：

### 2.1 时钟与 PLL（主控区 0x100~0x128）

| 地址 | 名称 | 排查点 |
|---|---|---|
| 0x0104 | FPGA 内部 PLL 锁定 | bit0=250M、bit1=260M 锁定指示，1=锁定 |
| 0x0110 | 5331/xx18 参考输入选择 | 0=PHY synce 1.953125M，1=SW 第0路，2=SW 第1路（默认 1） |
| 0x0114 | PLL 80227 状态 | bit1=LD 失锁指示（0=锁定/1=失锁）；bit0=STATUS、bit2=REFMON |
| 0x0118 | PLL 80227 控制 | bit0=复位（低有效）、bit1=下电（低有效），复位值 3 |
| 0x0128 | syncePP1S 配置选择 | 0=PHY PP1S，1=SW 第0路 PP1S，2=PHY 第1路 PP1S |

### 2.2 单板及时钟主备（时钟同步区 0x4300~0x4378）

| 地址 | 名称 | 排查点 |
|---|---|---|
| 0x4300 / 0x4304 | B 类 / B2 类错误 | 1=发生 |
| 0x4308 | CPU_READY（AD80227 初始化完成） | 软件置 1 才使能主备竞争 |
| 0x4314 | 软件主备切换 | 后台切换命令，高有效 |
| 0x431c | 主备控制 MS_CTL | bit0=主备逻辑与驱动器使能；bit1=启动竞争（先 EN 再 ACT）；bit2=本板告警；bit3=本板运行；bit4=倒换请求（延时 100us）；bit5=复位输出 |
| 0x4320 | 主备状态 MS_STATE | bit0=对板上电；bit1=对板运行；bit2=本板主(1)/备(0)；bit3=对板主备；bit4=对板告警；bit5=对板复位；bit6=对板请求倒换 |
| 0x4324 | 本板时钟状态 THIS_CLOCK_STATUS | 10110=主板正常 / 01110=备板正常 / 10100=主板B类 / 01100=备板B类 / 10010=主板A类 / 01010=备板A类 / 01011=备板b2 / 10011=主板b2 / 00001=初始上电 |
| 0x4328 | 对板时钟状态 | 编码同 0x4324 |
| 0x4348 | A 类错误 | 1=发生过 |
| 0x4370 | 时钟主备状态 | 1=主，0=备 |
| 0x4408 | 主备时钟数据屏蔽 | 写 0x55aa 关闭时钟（默认打开） |

### 2.3 告警及检测（基址 0xc000）

通用告警控制：`0xcxx0` 清除（bit0 告警、bit1 计数）、`0xcxx4` 模拟、`0xcxx8` 状态（bit0 事件=发生过/bit1 实时=当前有）、`0xcxxc` 计数（65535 回 0）。

**时钟错误类型** `0xc30N`：bit0=B2 类、bit1=B 类、bit2=A 类。

**A 类错误详细** `0xc40N`（每 bit 一路告警，1=发生）：

| 地址 | 含义 | 地址 | 含义 |
|---|---|---|---|
| 0xc40N | 10M 时钟丢失 | 0xc49N | 参考 pp1s 错误 |
| 0xc41N | 80227 失锁 | 0xc4aN | 参考 pp1s 过长 |
| 0xc42N | 260M PLL 失锁 | 0xc4bN | 参考 pp1s 过短 |
| 0xc43N | 250M PLL 失锁 | 0xc4cN | 第0路 fsync 丢失（仅主板） |
| 0xc44N | 下发 61.44M 时钟错误 | 0xc4dN | 第1路 fsync 丢失（仅主板） |
| 0xc45N | 主备 61.44M 时钟错误 | 0xc4eN | OCXO 输入 10M 丢失（5531/35081 方案） |
| 0xc46N/0xc47N | 反馈第0/1路 61.44M 错误 | | |
| 0xc48N | 鉴相 250M 时钟错误 | | |

**反馈 fsync / decode_pp2s** `0xc50N`~`0xc5dN`：每路按「错误/失步/早到/晚到」；`0xc58N`~`0xc5dN` 为从 fsync 解析 pp2s 的错误/过长/过短。

**PP1S 参考源检测** `0xc60N`~`0xc7dN`：gps_pp1s（0xc60N 错误 / 0xc61N 过长 / 0xc62N 过短）、485pp1s 两路（0xc63N/0xc66N）、1588pp1s（0xc69N）、虚拟 pp1s 三路（0xc6cN/0xc78N/0xc7bN）、decode_pp1s（0xc6fN）、vsc0/vsc1（0xc72N/0xc75N）——每类均按 错误/过长/过短 三寄存器连续排列。

**1588 + SyncE** `0xc80N`~`0xc89N`：phy 第0/1路时钟错误（0xc80N/0xc81N）、sw 第0/1路时钟错误（0xc83N/0xc85N，0xc82N/0xc84N 寄存器不使用）、1588_250M 时钟错误（0xc86N）、外部 SyncE pp1s 过短/过长/丢失（0xc87N/0xc88N/0xc89N）。

**I2C 应答错误** `0xca0N`~`0xca5N`：OCXO（地址/数据）、SFP（地址/数据）、QSFP（地址/数据）——无应答即告警。

### 2.4 中断（基址 0xd000）

| 地址 | 名称 | 说明 |
|---|---|---|
| 0xd000 | PP1S 中断清除 | bit0=清除事件，高有效 |
| 0xd004 | PP1S 中断设置 | bit0=屏蔽输出管脚、bit1=模拟中断 |
| 0xd008 | PP1S 中断寄存器 | bit1=实时（1ms 低脉冲）、bit0=事件（软件清） |
| 0xd00c | 普通中断清除 | 每 bit 对应一路中断 |
| 0xd010 | 普通中断模拟 | bit0=时钟错误（本板对板时钟差 A/B/B2 类）；bit1=主备切换（主变备）；bit2=状态切换（备响应软件请求）；bit3=对板复位（EPLD 单独复位 FPGA）；bit4=对板拔出（检测不到对板时钟）；bit14=面板主备按键 |
| 0xd014 | 普通中断掩码 | 只屏蔽输出管脚，不屏蔽内部寄存器 |
| 0xd018 | 普通中断状态 | 实时状态，bit 定义同 0xd010 |
| 0xd01c | 普通中断事件 | 高有效，软件清 |

### 2.5 光模块告警（基址 0xd020）

公共 bit 定义：`bit9-8`=QSFP2 中断/不在位；`bit7-6`=QSFP1 中断/不在位；`bit5-3`=光模块2（los/错误/不在位）；`bit2-0`=光模块1（los/错误/不在位）。

| 地址 | 名称 | 地址 | 名称 |
|---|---|---|---|
| 0xd020 | 告警事件清零（上升沿） | 0xd034 | SFP 不在位次数（[15:8]模块2 [7:0]模块1） |
| 0xd024 | 告警错误模拟 | 0xd038 | SFP 错误次数（tx_fault） |
| 0xd028 | 告警状态（实时） | 0xd03c | SFP los 次数（rx_los） |
| 0xd02c | 告警事件指示 | 0xd040/0xd044 | QSFP 不在位/中断次数 |

## 3. 排查决策链

**场景 A：时钟失锁 / A 类错误（主备倒换前兆）**
1. 读 `0x4324`/`0x4328`（本板/对板时钟状态编码）确认当前主备与错误类别（A/B/B2）。
2. `0x4348` A 类错误置位 → 到 `0xc40N` 组逐 bit 定位：10M 丢失（0xc40N）→ 80227 失锁（0xc41N）→ 250M/260M PLL（0xc43N/0xc42N）→ 下发/主备/反馈 61.44M（0xc44N~0xc47N）→ 鉴相 250M（0xc48N）→ 参考 pp1s 错误/过长/过短（0xc49N~0xc4bN）→ fsync 丢失（0xc4cN/0xc4dN，仅主板）→ OCXO 10M（0xc4eN）。
3. 排除外围：`0xca0N`~`0xca5N` I2C 应答（OCXO/SFP/QSFP 器件是否在线）、`0xd020` 组光模块告警。
4. 中断佐证：`0xd01c` 事件 bit0=时钟错误、bit3=对板复位、bit4=对板拔出。

**场景 B：B 类 / B2 类错误（参考源质量）**
1. `0x4300`/`0x4304` 置位 → `0xc30N` 确认错误类型。
2. 参考源检测：`0xc60N`~`0xc7dN`（gps/485/1588/virtual/vsc/decode pp1s 错误/过长/过短）与 `0xc50N`~`0xc5dN`（fsync/pp2s 错位失步早到晚到）。
3. 同步通路配置核查：`0x0110`（参考输入选择）、`0x0128`（syncePP1S 选择）、`0x4208`（PPS 面板输出选择）。

**场景 C：1588 / SyncE**
1. `0xc80N`~`0xc89N`：phy/sw 路时钟错误、1588_250M、外部 SyncE pp1s 过短/过长/丢失。
2. 结合 `0x0114`（80227 状态）与 `0x0200`/`0x0204`（SW 恢复钟有效 / PHY 状态）判断恢复时钟源。

## 4. 与现有能力衔接

- **寄存器语义**：`clk-field-dictionary.yaml` 的 `ITRAN_FPGA_REG` 段收录以上排查关键寄存器；子 Skill 的证据规则可在 `mechanism`/`decision` 中引用寄存器值（如"0x4324 时钟状态为 10010=主板 A 类"），但规则本身仍需真实工装/诊断日志验证。
- **工装日志**：ITRAN 主备/时钟告警若以 `寄存器名=值` 或 `调用:...接口,参数:[...],返回值:[...]` 形式出现在日志，接口调用行复用 `parse_cloudmat.py` 的 `interface_calls` 解析；寄存器原始地址读法按本表解释。
- **时钟日志**：`clockstatuslog` 的 CLK 语义与 `parse_clock.py` 不因本表改变；本表服务于 FPGA 寄存器/告警位层面（主备、PLL、pp1s 检测）的补充解释。
- **不与 VSWe 混用**：VSWe 的 `VSWE_FIXTURE_REG`/`VSWE_FIXTURE_BSP` 与 ITRAN 寄存器按单板域隔离，禁止跨单板套用。

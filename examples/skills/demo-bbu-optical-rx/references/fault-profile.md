## 1. 故障标识

- 规范名称：光模块接收光功率异常
- 别名：收光异常、光功率异常、RX_LOSS、接收光功率过低
- 告警码：无
- 设备形态：BBU、ITBBU、SDR
- 制式：待补充
- 版本范围：待补充
- 执行模式：script
- 故障大类：光模块

## 2. 故障现象

- 可感知现象：光口 RX_LOSS 告警；日志出现接收光功率低于门限
- 描述关键词：光模块、收光、光功率、RX_LOSS、误码、光口

## 3. 分析步骤与判定决策链

### S1：检索收光异常直接证据
- 目标：确认日志中是否存在 RX_LOSS 或收光功率过低证据
- 规则 **E1**（text）：日志出现 RX_LOSS 或收光功率过低
  - 路径：`**/*.log, **/*optical*.txt, **/*.txt`
  - any_of: ['RX_LOSS', '收光功率过低', 'RX power low', '光功率异常']
- 命中 → 命中收光异常直接证据
- 未命中 → 无收光异常证据

## 4. 根因与处理方案

### R1：光模块接收光功率低于门限
- 判定条件：`E1`
- 关联时序约束：自动（condition 中肯定引用的规则两两相关的约束）
- 置信度：medium
- 处置动作：
  1. 清洁尾纤与光口，检查连接器是否松动
  2. 用光功率计测量收光功率，与模块规格门限比对
  3. 检查对端发光功率与光模块告警
  4. 更换尾纤或光模块后复测误码与 RX_LOSS 是否消失
- 前提条件：具备光功率计与备用尾纤/光模块
- 风险：拔插尾纤会影响业务，需在变更窗口执行
- 回退：恢复原尾纤/模块并保留测量数据
- 升级路径：更换模块后仍收光不足时，检查对端与光纤链路

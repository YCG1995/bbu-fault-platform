# BBU FaultScope 1.22.0 版本说明（指定技能 / 全量证据 / 执行轨迹）

1.22.0 在 1.21.0 基础上完成 P1–P3：诊断模式支持“指定技能”，任务详情展示全量证据与根因决策卡，诊断/工坊接入执行轨迹；同时补齐归档安全矩阵与复杂规则回归。数据库 schema 从 18 升到 **20**。

## 一、P1 指定技能诊断

- 新建诊断提供三种模式：快速定位、深度分析、指定技能。
- `mode=skill` 必须且只能提交一个 `skill_name`，技能状态必须为 `ready` 或 `degraded`；缺失、无效或未就绪返回 400。
- 指定技能模式只执行该技能，计划标记 `source=user_selected`，不触发 AI 扩选、不补规划；快速/深度模式忽略旧 `skill_names` 字段。
- 三个入口：
  - 新建诊断页三张模式卡，选中“指定技能”后显示单选技能下拉；
  - 技能库卡片“用此技能诊断”；
  - 系统信息 → 任务空间顶部“按技能诊断”选择器。
- 草稿保存/恢复包含 `mode` 与 `skill_name`；切回快速/深度时清空并隐藏技能选择。
- 任务列表、任务详情和报告模式标签均支持“指定技能”。

## 二、P2 全量证据与恢复上传

- `GET /api/tasks/<id>/evidence` 支持 `limit`/`offset`，返回 `total`；任务详情分页拉全量证据，不再只使用仲裁候选裁剪后的 4 条。
- 证据按“根因 + 技能 + 规则”聚合；默认显示前 5 组，提供“查看全部 N 组”、搜索框、技能筛选和根因筛选；长路径折叠、原文可展开，页面显示总条数/组数。
- 新增“根因决策卡”：展示必要证据已命中/缺失、反证规则是否命中、近邻鉴别、缺失规则与限制；明确“缺扫描不等于反证”。
- 恢复验证回传从 JSON 改为 multipart 文件，REST 冒烟断言 `uploaded=true`、`sha256`、文件名、大小和抽取文本。

## 三、P3 工具与回归

- 新增助手/MCP 工具 `create_skill_diagnosis`：参数 `source_task_id`、`skill`、可选 `title`/`description`；复用来源任务日志创建 `mode=skill` 任务。
- 权限：仅任务所有者可复用来源；管理员可复用任意用户任务；来源必须存在、输入可用、日志位于 `data/uploads` 且文件存在；队列满返回 429。
- MCP 写模式调用要求 `confirm=true`，审计记录 `task.create` 且 `via=assistant`。
- 归档安全矩阵新增：ZIP 路径穿越、绝对路径/盘符/UNC 拒绝、ZIP 炸弹预算、损坏归档不当普通日志、加密 ZIP 跳过、嵌套 ZIP。
- 复杂规则回归新增：时间窗内外、多站点时序隔离、数值严格边界与连续超限、CSV/XLSX 列匹配、多根因冲突排序。
- 修复两个真实缺陷：
  - xlsx `workbook.xml.rels` 的绝对 Target（`/xl/worksheets/...`）被拼成 `xl/xl/...`，导致整表漏检；
  - 归档绝对路径成员先 `lstrip("/")` 再校验，导致 `/absolute.txt` 被当相对路径写入。

## 四、执行轨迹

- 新增 `trace_runs` 表与 `bbu/trace.py`；诊断和工坊记录模型调用、工具调用、计划、校验、错误与耗时。
- 管理员可通过“执行轨迹”列表/详情查看；任务详情新增“执行过程”页签，工坊任务提供“查看过程”入口。
- 轨迹仅管理员可见；普通用户界面不暴露入口。

## 五、升级说明

从 1.21.0 升级到 1.22.0：

- schema 18 → 20：新增 `trace_runs` 表与 `task_drafts.skill_name` 列；旧库启动时幂等补表/补列。
- 版本号 1.22.0；离线包 `bbu-fault-platform-1.22.0-offline.tar.gz`。
- 迁移前按标准流程备份数据库与运行数据。

```bash
sha256sum -c bbu-fault-platform-1.22.0-offline.tar.gz.sha256
tar -xzf bbu-fault-platform-1.22.0-offline.tar.gz
sudo bash bbu-fault-platform/deploy/upgrade_offline.sh \
  --package /path/to/bbu-fault-platform-1.22.0-offline.tar.gz
```

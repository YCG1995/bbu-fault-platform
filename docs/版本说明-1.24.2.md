# BBU FaultScope 1.24.2 版本说明（技能工坊空态布局）

1.24.2 优化技能工坊无草稿时的首屏布局；数据库 schema 保持 **21**，工坊接口和任务行为不变。

## 一、问题

1.24.1 及之前，工坊无草稿时会生成“草稿列表 + 草稿详情”两栏：

- 左侧仍渲染一个空的“草稿 0 个”卡片，并重复显示“还没有草稿”；
- 右侧渲染大面积空白的“选择一个草稿”占位；
- 两块空态语义重复，首屏空间利用率低，也缺少“下一步能做什么”的说明。

## 二、调整

无草稿时改为单张全宽起始卡：

- 左侧：工坊图标、`0 个草稿` 状态、标题“从一段真实故障资料开始”、资料范围说明，以及主按钮「粘贴资料生成技能」；按钮下方标注支持文本、日志片段与 ZIP / tar.gz 日志包。
- 右侧：五步流程说明（粘贴资料 → AI 语义提取 → 确定性编译 → 案例回归 → 发布技能），让首次进入的用户知道系统会完成哪些步骤。
- 有草稿后仍恢复原来的“左侧草稿列表 + 右侧草稿详情”工作区；已有的草稿选择、删除、编辑、审查、回归和发布流程不变。
- 390px 下起始卡改为单列，流程纵向排列，不产生横向滚动。

## 三、验证

- 1440px 与 390px 均完成浏览器截图检查，无 JS 错误、无横向溢出。
- 单元/集成测试：**222 passed**。
- REST 全量冒烟：**152/152**。
- 1.24.2 离线包安装后健康返回 `1.24.2`，schema 21。
- 1.24.1 → 1.24.2 升级成功，schema 保持 21。

## 七、未完成与风险

1. **20 条真实 golden 未收集**：数据库仍只有 3 条 `split=test,status=golden`。评测门禁已可运行，但指标只代表现有小样本。
2. **UI 全动作未逐条实测**：257 个实例中只实测了关键路径；权限组合、所有弹窗分支仍需专项回归。
3. **私有 MaaS 地址**：`model_discovery_allow_private` 默认 `false`。若现场模型服务在私网/回环，需要显式设置 `BBU_MODEL_DISCOVERY_ALLOW_PRIVATE=1`，否则模型发现会被 netguard 拒绝。
4. **Ubuntu 16.04 一键包**：缺少内置 CPython 运行时，未生成；Linux/Windows 包已生成。
5. **审批与生命周期入口**：核心能力在服务层，尚未新增独立 HTTP/UI 管理页；工坊发布已可选接入审批门禁。
6. **schema 22 升级/回滚演练**：仅在临时库验证迁移结果，未在生产规模数据上做升级与回滚计时。

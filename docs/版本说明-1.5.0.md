# 版本说明 · 1.5.0（R3 诊断工作台体验）

发布对象：现场工程师、复核专家、平台管理员  
基线：1.4.0（R2 用户与专家管理）  
数据库：schema 5 → 6（新增 `task_drafts`、`notifications`，旧数据无损迁移）

## 本次交付

### 1. 新建任务草稿与上传体验
- 表单自动保存（标题、描述、模式、模型、灰度开关），刷新或重新进入可恢复草稿与已上传日志包。
- 文件选择后立即上传，显示单文件/总进度、速率、失败原因，支持取消、重试、移除。
- 提交防重：上传中或提交中禁用按钮；离开页面前提示未保存内容；提交成功自动删除草稿。
- `POST /api/tasks` 支持 `draft_id`，从草稿复制文件到任务目录；无文件且无草稿返回 400。

### 2. 阶段时间线与结论解释
- 任务详情返回 `stage_timeline`：受理、盘点、AI 规划、技能执行、补规划、仲裁、报告、完成；包含开始/结束、耗时、事件数、当前/失败态。
- 新增 `next_action`，按状态给出下一步操作建议。
- 前端新增“阶段时间线”卡片和“为什么得出这个结论？”折叠说明。

### 3. reviewer 待复核
- reviewer 任务列表增加“待复核”标签页；`GET /api/tasks?review_status=pending` 仅返回分配给本人且未复核的终态任务。
- `/api/stats` 增加 `pending_reviews`；工作台提示待复核数量。
- 复核意见支持本地草稿，关闭弹窗后重新打开自动恢复；提交成功清除草稿。

### 4. 站内通知
- `GET /api/notifications`、`POST /api/notifications/{id}/read`、`POST /api/notifications/read-all`。
- 任务完成、需补数据、失败、取消、复核分配、账号状态变化写入通知；读取时尊重个人 `notification_prefs`。
- 顶栏铃铛、未读角标、通知列表、30 秒轮询。

### 5. 全局搜索
- `GET /api/search?q=`，按角色过滤：
  - 管理员：任务、案例、技能、用户；
  - 工程师：本人任务、本人/公共案例、技能；
  - reviewer：仅本人创建或被分配的任务。
- 顶栏搜索入口、250ms 防抖、分组结果；任务/技能/用户可跳转，案例展示元数据。

### 6. 首次使用与移动端/无障碍
- 工作台按角色展示“开始使用”清单：配模型、装技能、建任务、接复核、处理待复核。
- 375px 下任务/用户/审计宽表格转卡片，无整页横向滚动；标签页横向滚动，触控目标不小于 40px。
- 弹窗支持 Esc 关闭、Tab 焦点循环、关闭后焦点回收；搜索框自动聚焦。
- 后端统计补充 `models_enabled`、`tasks_total`。

## 离线包

- 文件：`dist/bbu-fault-platform-1.5.0-offline.tar.gz`
- SHA256：`d4bcc85f86d082b0b91978e202648b2a97fafde0686614d3ec79fe03d995cdb1`
- 升级方式：

```bash
sha256sum -c bbu-fault-platform-1.5.0-offline.tar.gz.sha256
mkdir -p /tmp/bbu-release-1.5.0
tar -xzf bbu-fault-platform-1.5.0-offline.tar.gz -C /tmp/bbu-release-1.5.0
sudo bash /tmp/bbu-release-1.5.0/bbu-fault-platform/deploy/upgrade_offline.sh
```

跨 schema 回滚必须显式带 `--with-state`：

```bash
sudo bash /opt/bbu-fault-platform/deploy/rollback_offline.sh \
  --backup /var/lib/bbu-fault-platform/backups/<快照目录> --with-state
```

## 已知边界
- 全局搜索为 SQLite `LIKE` 模糊匹配，适合单机规模；数据量增长后可替换 FTS5。
- 通知为站内通知，不发送邮件/短信；通知偏好通过 `PUT /api/profile` 的 `notification_prefs` 配置。
- 移动端以“可用”为目标，复杂证据对比仍建议桌面端。

# 版本说明 · 1.4.0（R2 用户与专家管理）

日期：2026-11-25  
基线：1.3.2（R1 账号安全）

## 1. 本版改动

### 邀请开户与账号状态

- 新增一次性激活码开户：管理员填写用户名、显示名、角色、班组/站点和有效期，系统生成 `XXXX-XXXX` 激活码。
- 激活码默认 24 小时有效，可选 72 小时或 7 天；数据库只保存 SHA256 哈希，列表接口不返回激活码，创建响应只显示一次。
- 待激活账号以 `status=invited` 出现在用户列表中；激活后原位转为 `active`，不重复创建账号。
- 激活码单次使用、可撤销、过期失效；使用、撤销、过期失败均写审计。
- 账号状态统一为 `invited / active / disabled / expired`；原 `active` 字段保持同步，旧账号迁移时 `active=0` 自动标为 `disabled`。
- 支持账号到期时间；到期后下次请求立即返回 401，管理员可在用户页延长或清空到期时间。

### 用户管理与个人中心

- 用户列表改为服务端分页、搜索与筛选，支持用户名/显示名/班组/站点、角色和状态；1000 条账号不会全量下发。
- 支持批量停用（撤销会话、不删除审计关联账号）、用户详情、重置密码、强制下线、邀请码生成与撤销。
- 用户详情展示基本资料、最近登录时间/IP/UA、活跃会话、最近审计、任务/复核计数。
- 新增个人中心：显示名、通知偏好、密码、会话查看与撤销；用户名和角色仍由管理员维护。
- 保留“至少一个启用管理员”和“不能停用当前登录账号”两道保护。

### 专家（reviewer）权限

- 新增 `reviewer` 角色，可查看被分配任务、提交复核、下载报告；不能创建任务、管理用户/模型/技能、查看系统配置。
- 管理员可在任务详情分配或调整复核专家；任务列表和统计按“本人创建 + 被分配”过滤。
- 任务取消/重跑仅任务 owner 或管理员可操作，reviewer 前端不再显示这些按钮。
- 专家访问用户、模型、系统信息、审计等管理接口统一返回 403。

### 审计

- 审计页支持时间、用户、动作、对象、结果筛选，服务端分页。
- 新增 CSV 导出，最多 10,000 条；导出动作本身写入审计。
- 登录审计记录 UA；用户详情可直接看到最近登录 IP 与 UA。
- 登录失败仍按 IP/账号分类计数，前端不暴露账号是否存在。

## 2. 数据库迁移

- `schema_version` 从 4 升至 5，服务启动时自动执行。
- `users` 增加 `status/team/site/expires_at/invited_by/invited_at/updated_at/notification_prefs`。
- `tasks` 增加 `reviewer_id/reviewer_assigned_at`。
- 新建 `user_invites` 表及激活码唯一索引。
- 迁移兼容旧库：旧 `active=0` 用户转 `disabled`，旧用户的 `updated_at` 回填 `created_at`，不删除任何用户或审计记录。
- 升级前仍由 `deploy/upgrade_offline.sh` 自动备份数据库、密钥和旧代码；回滚使用 `deploy/rollback_offline.sh`。

- 单元测试：46/46 通过（新增 schema 4→5 迁移用例）。

- 端到端：登录、上传、单技能、多技能并行、一次补规划、自动草稿、HTML 报告全部通过。
- 推理端到端：CPU 中断异常根因与报告推理章节通过。
- 浏览器 UI 冒烟（Playwright）：用户管理、审计筛选、管理员分配专家、reviewer 任务详情/导航、激活表单全部通过，无控制台错误。
- 真实升级演练：1.3.1（schema 4）→ 1.4.0（schema 5）→ `--with-state` 回滚 1.3.1（schema 4），健康检查版本、用户状态列、邀请表和升级快照均符合预期。

## 4. 已知边界

- TOTP MFA、SSO、管理员安全设置页按计划列为 P2，本版未实现。
- reviewer 暂不支持自助接受/拒绝任务分配；由管理员调整。
- 工程师当前仍可对自己创建的任务提交复核；如现场要求“只能专家复核”，可在下一版收紧。
- 浏览器通知仅保存偏好，站内通知与全局搜索在 R3 实现。

## 5. 升级方式

```bash
sha256sum -c bbu-fault-platform-1.4.0-offline.tar.gz.sha256
mkdir -p /tmp/bbu-release-1.4.0
tar -xzf bbu-fault-platform-1.4.0-offline.tar.gz -C /tmp/bbu-release-1.4.0
sudo bash /tmp/bbu-release-1.4.0/bbu-fault-platform/deploy/upgrade_offline.sh
curl -fsS http://127.0.0.1:8080/api/health
```

升级后 `/api/health` 与页面左下角版本应为 `1.4.0`，用户页可见状态筛选、邀请开户和审计导出。

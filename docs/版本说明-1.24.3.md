# BBU FaultScope 1.24.3 版本说明（任务空间布局优化）

1.24.3 优化“系统信息 → 任务空间”页面布局；数据库 schema 保持 **21**，接口字段与释放行为不变。

## 一、问题

原页面在 1440px 与窄屏下存在四处明显的布局问题：

- 标题说明在左、批量释放下拉与两个按钮在中间，右侧留出大段空白，操作区没有形成统一的右侧工具栏；
- “按技能诊断”条带中的技能下拉继承了全局 `.select` 的 `width: 100%`，在 flex 容器内把「按技能诊断」按钮挤到第二行；
- 四个空间统计数字使用嵌套 `.card.stat`，卡片内再套卡片，层级偏重；
- 没有任务时仍渲染 8 列表头和一行巨大的空白表格，“暂无任务”缩在表格中间，首屏空态不完整。

## 二、调整

- **页头工具栏**：标题与说明保留在左，释放模式下拉、「释放选中」、「重新统计」统一靠右，桌面一行排布，窄屏自动换行。
- **技能诊断条**：图标 + 标题说明在左，技能下拉与「按技能诊断」在右；下拉改为固定 260px、按钮同高，桌面不再换行。
- **空间概览**：四张统计卡改为平铺 `.storage-stat`，不再嵌套 `.card`，数字、标签与图标保持一行；移动端单列展示。
- **释放规则**：改为带图标与“磁盘剩余”标签的规则条；桌面两段说明，移动端说明占满宽度，磁盘信息另起一行。
- **任务清单**：有任务时增加“任务清单 / 共 N 个任务”小节，再渲染表格；无任务时不再输出表头和空行，改为居中的空态卡与「重新统计」按钮。
- **移动端**：≤720px 时表格转任务卡片，勾选框在右上，任务标题、状态、原始输入、解压文件、其它产物、合计与操作纵向排列；不可释放任务不显示空操作行，390px 无横向溢出。

## 三、验证

- 新增 `tests/ui_storage_smoke.py`：空态、任务清单、工具栏靠右、技能诊断控件同高同行、390px 卡片化与无横向溢出；桌面/移动端截图均无 JS 错误。
- 既有单元/集成测试：**222 passed**。
- REST 全量冒烟：**152/152**。
- 1.24.3 离线包安装后健康返回 `1.24.3`，schema 21；1.24.2 → 1.24.3 升级成功，schema 保持 21。

# BBU FaultScope 1.24.8 版本说明（模型配置平台预设与模型发现）

1.24.8 优化「模型接入 → 添加/编辑模型配置」：平台预设、Base URL 与模型名下拉、获取模型列表和 `max_tokens` 建议值一次完成；数据库 schema 保持 **21**。

## 一、使用方式

1. 管理员进入「模型接入」，点击「添加模型」或已有配置的「编辑」。
2. 在「平台预设」选择公司 MaaS、OpenAI、DeepSeek、通义千问、Anthropic、Kimi、智谱、硅基流动、Gemini 兼容模式、火山方舟、腾讯混元或本地 Ollama；选择后自动带出 Base URL、协议、常用模型名和建议 `max_tokens`。
3. Base URL 仍可直接输入；也可以从输入框下拉列表选择常用平台地址。自定义或内网地址选择「自定义 / 手动填写」。
4. 模型名可从下拉选择，也可直接输入；点击「获取」会按当前 Base URL、协议和 API Key 请求服务端模型列表，成功后模型名下拉更新为实际可用模型。
5. 选择模型后自动填入建议 `max_tokens`；该值是建议值，不是账号额度硬限制，可按实际额度修改。
6. 点击「测试当前填写值」验证连通性，或「添加 / 保存」写入配置。

## 二、代码改动

- `web/assets/js/model_presets.js`：新增 12 个常用平台预设和常用模型/建议 `max_tokens`；仅用于表单填充，不改变后端协议校验。
- `web/assets/js/page_admin.js`：模型弹窗增加平台预设、Base URL datalist、模型 datalist、「获取」按钮和 `max_tokens` 自动带出；保留手动输入；获取期间按钮防重复，Base URL/协议变更后忽略过期结果。
- `bbu/ai.py`：新增 `list_models()`，OpenAI 兼容读取 `{base}/models`，Anthropic 读取原生 `{base}/v1/models`；15 秒超时、最多返回 200 个、去重；只返回模型名，不触发推理。
- `bbu/api.py`：新增管理员接口 `POST /api/models/discover`，支持当前填写值或 `model_id` 复用已保存密钥；仅允许 `http/https` URL，错误返回 400，不把 API Key 写入响应或审计。
- `tests/api_full_smoke.py`：新增模型发现路由覆盖，REST 预期从 **152** 增至 **153**。
- `tests/test_ai_protocols.py`：新增 OpenAI/Anthropic 模型列表路径与鉴权头测试。
- `tests/ui_model_presets_smoke.py`：新增 UI 冒烟，覆盖平台切换、Base URL/模型下拉、获取列表、`max_tokens` 自动带出与保存。

## 四、边界与升级

- 版本号 **1.24.8**；schema 保持 **21**，无数据库迁移。
- 「获取」依赖当前 Base URL 可访问且 API Key 有效；Anthropic 兼容服务若未实现模型列表端点，会返回 400 并保留手动填写。
- 非 Mock 配置仍需 API Key；本地 Ollama 可填任意非空值。平台预设中的模型名和 `max_tokens` 为常用建议，实际可用性以服务端为准。
- 从 1.24.7 升级到 1.24.8 可直接使用标准离线升级或 Windows 网页上传更新；运行数据与模型配置保留。

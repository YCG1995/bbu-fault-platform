# BBU FaultScope 1.20.3 版本说明（平台助手知识库检索 P0/P1）

发布日期：2026-11-26

本版本只优化平台助手与 MCP 共用的本地 Markdown 知识库检索，不引入向量模型、不增加第三方依赖；助手工具 schema、`platform://docs/<slug>` 来源格式、数据库 schema 17 和现有权限边界保持不变。

## 一、为什么改

原实现是 Markdown 标题分块 + 手工关键词加分，存在五个影响现场问答的瓶颈：

1. 标题扫描没有识别代码围栏，代码块里以 `#` 开头的 shell 注释被当成章节标题，产生“1) 上传 tar.gz…”“应返回…”等伪章节和错误 breadcrumb。
2. 手工词频加分没有长度归一化，长块容易靠重复词堆分；标题、文档标题和正文的权重也不稳定。
3. 没有 FAQ/同义词扩展，也没有对 `NoNewPrivileges`、`systemctl`、`U...` 任务号、`/api/...` 路径等精确标识符单独加权。
4. 摘要优先找完整 query，找不到就取正文开头，用户看到的来源片段可能不是答案所在位置。
5. 意图路由只覆盖“新建诊断”，部署、升级、回滚、sudo、账号、模型、工坊、MCP 等问题没有稳定的文档/章节路由；本地降级路径不做多轮追问改写。

## 二、P0：先修分块与召回

- **修复 fenced code block 标题误判**：扫描 Markdown 时跟踪 ```/~~~ 围栏，围栏内的 `#` 行只作为正文，不再切块；现有升级文档的伪章节和错误 breadcrumb 消失。
- **FAQ/同义词扩展**：增加 30+ 条常见问法映射，只用于 query 词项扩展和文档/章节路由，例如“新建诊断/发起诊断”“改密码/重置密码”“升级助手/sudo/systemctl”“网页升级/上传升级”“一键包/初始包/Ubuntu 16”“MCP/Token/令牌”。
- **精确标识符加权**：对任务号、错误码、路径、命令、版本号等精确 token 额外加权，`NoNewPrivileges`、`systemctl`、`U...`、`/api/...` 不再只依赖普通分词。
- **滑窗摘要**：按 query 词覆盖度在正文内选择 420 字窗口，保留代码内容，只去掉 Markdown 装饰；命中位置不在开头时也能展示到答案附近。

## 三、P1：BM25F + 意图路由 + 多轮改写

- **纯 Python BM25F**：字段权重为 heading 3.0、doc title 2.0、body 1.0，使用 `k1=1.2`、`b=0.75` 做长度归一化；不引入 numpy、onnxruntime、向量库或新模型。
- **保留原有排序约束**：DOC_PRIORITY、版本/变更标题降权、标题块轻微加权、按 `(slug, heading)` 去重、top-k 限制均保留；`search_docs` 返回字段和 `platform://docs/<slug>` 来源格式不变。
- **规则式意图路由**：覆盖新建诊断、升级/回滚/升级失败、网页升级、Ubuntu16 一键包、sudo/NNP、1.20.2 发布说明、账号、模型接入、技能工坊、MCP、架构、Windows、诊断推理数据等常见问题；路由只作用于目标文档/章节，不替代 BM25 全库召回。
- **多轮 query 改写**：本地降级路径把“那回滚呢”这类追问与上一轮用户问题合并后再检索；模型规划提示也要求先把追问改写成独立问题，再调用 `search_docs`。

其他验证：

- 助手/MCP 契约：原有“怎么新建诊断”必须命中“使用手册”的断言保持；`search_docs` schema 与返回结构未变。

- 无新增第三方依赖，离线包体积变化仅来自源码与文档。

## 五、升级方式

从 1.20.2 升级到 1.20.3 没有数据库 schema 变更，沿用标准离线升级：

```bash
sha256sum -c bbu-fault-platform-1.20.3-offline.tar.gz.sha256
tar -xzf bbu-fault-platform-1.20.3-offline.tar.gz
sudo bash bbu-fault-platform/deploy/upgrade_offline.sh \
  --package /path/to/bbu-fault-platform-1.20.3-offline.tar.gz
```

网页上传升级仍走 1.20.2 已修复的异步触发器；若现场仍报 `/usr/bin/systemctl: 没有那个文件或目录`，先按 `docs/升级助手sudo故障修复.md` 替换触发器。

## 六、已知限制

- 仍是规则 + 词法检索，不理解真正语义；口语化、跨领域同义词需要继续补 FAQ/别名或路由。
- 54 条评测集是内部构造集，不等于真实用户分布；后续应把现场高频问法持续加入回归。
- BM25F 对小文档集合的 IDF 波动较敏感；当前 11–12 篇文档规模合适，文档数量大幅增加时需要重新校准字段权重和路由。
- 多轮改写只处理追问合并，不做完整对话摘要；模型路径仍依赖规划提示遵循改写要求。

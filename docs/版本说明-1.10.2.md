# 版本说明 1.10.2

基线：1.10.1（schema 10）→ 1.10.2（schema 10）
日期：2026-11-25

## 一、本版定位

1.10.2 是 1.10.1 的界面补丁，不新增功能、不改数据库 schema、不改 REST 契约。修复技能工坊等页面加载时出现的巨大 Flask/刷新图标。

## 二、问题与修复

### 1. 加载时出现巨大内联 SVG

- 根因：`page_workshop.js` 的“选择一个草稿”卡片把 `${icon('flask')}` 放在 `.empty` 外层；CSS 只给 `.empty svg` 设了 42px 尺寸，裸 SVG 没有宽高约束，会按容器铺满。
- 同类问题：多个页面的 `${icon('refresh')} 加载中…` 也直接放在 `.card-body`，同样没有尺寸。
- 修复：`app.css` 增加全局默认 `svg { width: 16px; height: 16px; flex: none; }`；各具体图标规则（`.brand-mark`、`.empty`、`.nav`、`.btn` 等）按原尺寸覆盖。
- 同时把工坊占位图的 Flask SVG 移入 `.empty`，恢复 42px 的预期大小。

### 2. 1.10.1 的 favicon 修复保留

- `web/favicon.ico`、版本化图标链接和缺失静态资源 404 逻辑继续保留。
- `?v=1.10.2` 用于刷新 1.10.1 的图标缓存。

## 三、验证

- 单元测试 83/83 通过。
- HTTP 全量冒烟 105/105 通过。
- 工坊加载态：`#draft-list svg` 为 16×16，`#draft-detail .empty svg` 为 42×42；不再铺满卡片。
- 数据库 schema 保持 10；1.10.1 → 1.10.2 不触发迁移。

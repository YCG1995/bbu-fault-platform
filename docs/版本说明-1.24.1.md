# BBU FaultScope 1.24.1 版本说明（用户每日用量图表）

1.24.1 在 1.24.0 的“用户每日用量”基础上增加图表视图；数据库 schema 保持 **21**，`GET /api/usage/overview` 返回字段不变。

## 一、页面变化

“用量统计”页的“用户每日用量”卡片调整为“图表 + 明细”：

- **每日堆叠柱图**：横轴为日期，纵轴为 Token 或调用次数，柱体按用户分段堆叠；鼠标悬停可查看某天某用户的数值。
- **指标切换**：卡片右上角提供「Token」/「调用次数」切换，两个指标使用同一批用户和日期。
- **图例合计**：图例显示每个用户在当前统计窗口内的合计；用户超过 6 个时，其余合并为“其他用户”，避免配色和标签不可读。
- **精确明细**：图表下方保留用户汇总表（活跃天数、调用、失败、输入/输出/总 Token、日均）和可展开的每日明细。
- **移动端**：390px 下图表自适应宽度，用户汇总表转为卡片布局。

## 二、统计口径

- 仍以 `user_daily` 为唯一数据源：按本地时区日期聚合每个用户的调用、失败、输入/输出/总 Token。
- 图表中的“调用次数”是模型调用次数，包含失败重试；失败次数在明细表中单独展示。
- 普通用户只拿到自己的 `user_daily`，因此图表只显示自己的柱体；管理员可看全部或指定用户。
- `user_daily` 只包含有调用的日期；图表横轴仍使用 `daily` 的完整日期，因此没有调用的日期会显示为空白。

## 三、权限与边界

- 本次为纯前端呈现改动，不改变权限判断：普通用户查询他人仍返回 **403**。
- 1.23.0 之前的历史任务没有逐调用事件，无法回填用户每日归属；任务级 Token 表仍保留历史汇总回退。
- 图表最多单独展示 6 个用户，其余合并；合并只影响图形和图例，汇总表仍逐用户列出。

## 四、升级说明

从 1.24.0 升级到 1.24.1：

- 版本号 1.24.1；离线更新包 `bbu-fault-platform-1.24.1-offline.tar.gz`。
- schema 保持 21；无数据库迁移。
- 升级前仍建议备份数据库与运行数据。

# 版本说明 1.8.1

基线：1.8.0（数据库 schema 8，不新增迁移）
日期：2026-11-25

## 一、本版内容

本版是 1.8.0 的兼容性修复版，主要解决 Windows 运行问题，并补齐内网 pip 源配置。

### 1. Windows 兼容

- 新增跨平台进程锁 `bbu/filelock.py`：
  - Linux 使用 `fcntl.flock`；
  - Windows 使用 `msvcrt.locking`，不再在模块顶层 `import fcntl`。
- `bbu/updater.py` 改为通过 `bbu.filelock` 加锁。
- `deploy/bbu_upgrade_helper.py` 不再顶层 import `fcntl`，并在独立执行时把程序根目录加入 `sys.path`。
- 修复技能子进程：
  - `start_new_session=True` 仅在 POSIX 传入；
  - Windows 超时/取消使用 `taskkill /PID <pid> /T /F` 结束进程树，不再调用 `os.killpg`/`os.getpgid`。
- Windows 下「系统信息 → 离线升级」默认显示手动更新提示，不再尝试 `sudo`/systemd。若确实配置了 `upgrade_helper_cmd`，仍可启用测试助手。
- 新增 `deploy/windows/start_platform.bat` 与 `docs/Windows运行说明.md`。

### 2. 内网 pip 源

新增：

- `deploy/pip.ini`（Windows）
- `deploy/pip.conf`（Linux）
- `deploy/windows/set_pip_mirror.bat`（复制到 `%APPDATA%\pip\pip.ini`）

源地址：

```text
https://artsz.zte.com.cn/artifactory/api/pypi/public-pypi-virtual/simple
```

同时配置 `trusted-host = artsz.zte.com.cn`。平台本身无第三方 pip 依赖，该配置用于后续安装诊断/运维辅助包。

### 3. Windows 使用方式

不提供 Windows 一键部署包。解压到可写目录后运行：

```bat
python run.py --host 0.0.0.0 --port 8080
```

或双击 `deploy\windows\start_platform.bat`。详见 `docs/Windows运行说明.md`。

## 二、升级说明

- 升级包：`dist/bbu-fault-platform-1.8.1-offline.tar.gz`（只含代码，不含 Python 运行时）
- Windows 手动包：`dist/bbu-fault-platform-1.8.1-windows.zip`（解压即用，不是安装器）
- 适用：已安装 1.8.0 一键部署包或常规离线包的 Linux 环境
- 数据库：schema 8，无迁移
- 升级方式：平台「系统信息 → 离线升级」上传，由 root/systemd 助手执行；不要用 `install.sh` 覆盖
- Windows：手动停止服务，备份 `data/` 与 `config.json`，覆盖程序目录后重启

## 三、验证

- 单元测试 63/63 通过，其中新增 `tests/test_windows_compat.py`：
  - 阻断 `fcntl` 导入后 `bbu.api` 与升级助手仍可导入；
  - Windows 无自定义助手时拒绝网页升级，POSIX 保持启用；
  - 文件锁互斥。
- 全量 REST 冒烟通过，E2E 单技能/多技能/补规划/报告通过。
- Linux 1.8.0 one-click 实例上做过薄更新包演练：数据库和用户保留，健康检查返回目标版本。

限制：当前构建环境没有 Windows 主机，`msvcrt` 分支和 `start_platform.bat` 未在真实 Windows 上执行；代码已通过导入隔离测试，建议首次在 Windows 上按文档启动并跑一条演示任务。

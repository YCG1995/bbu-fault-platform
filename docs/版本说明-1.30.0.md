# BBU 故障诊断平台 1.30.0 版本说明

发布日期：2026-11-27

## 主题

本版新增“故障查询知识库”：历史故障案例可被问答页、悬浮助手、MCP 工具与诊断规划复用。版本号从 1.29.0 升至 1.30.0，数据库 schema 升级到 24。

### 1. 检索内核

- 新增 `kb_text.py`、`kb_index.py`、`kb_retrieve.py`：纯标准库实现，不引入 jieba、numpy、向量库或 SQLite FTS5。
- 案例级索引，不以整条 CSV 行为检索单元；一个答案里多个【原因分析】按原因块拆成派生案例。
- 五字段（标题/现象/原因/方案/正文）BM25F，标题加权；实体索引覆盖板卡、领域、版本；短语索引、SimHash 近似标题召回。
- 查询侧多路召回（词法/实体/短语/SimHash）→ RRF 融合 → 确定性重排（词法、实体覆盖、标题覆盖、目标小节、质量、时效、完整性）→ 同根因去重。
- 无答案判定不依赖模型：无词项/实体/短语命中，或低于阈值且无实体时拒答，不生成推测根因。

### 2. 问答与引用

- `POST /api/kb/chat` 先检索，再在有真实模型时生成回答；无模型或模型失败返回本地抽取式回答并标记 `degraded=true`。
- 模型提示词要求只依据 `<cases>`，案例文本视为不可信数据；引用映射为 `K1..K6`，非法引用丢弃并回退到真实案例。
- 引用卡片可跳到 `#/kb/docs/{doc_id}`；查询日志与反馈落库，管理员可查看。

### 3. 导入与文档管理

- 支持 CSV/TSV、TXT/MD/HTML、DOCX、XLSX、文本型 PDF、PNG/JPEG/WebP。
- CSV 一行一文档；XLSX 一行一文档；DOCX/PDF 一文件一文档；图片和扫描 PDF 进入人工转写队列，不伪造解析成功。
- 导入任务后台执行，支持多文件、进度、取消、失败文件行与部分完成；文件 SHA 去重。
- 管理员可编辑标题/原文、启停、软删除、查看版本并恢复；工程师提交进入审核队列。
- 原文只对管理员开放；普通用户、索引、模型证据使用脱敏文本（姓名+工号、工号、电话、邮箱）。

### 4. 助手、MCP 与诊断联动

- 工具层新增 `search_fault_kb`、`get_fault_case`，工具总数由 21 增至 23；MCP read 模式可调用。
- 助手系统提示词区分“现场故障”和“平台用法”：现场故障优先故障知识库，平台用法用平台文档。
- 诊断规划检索历史相似案例作为“仅供参考”的假设线索；诊断报告追加“历史相似故障参考”附录，不进入 claim 校验，不影响根因仲裁。
- 新增 `#/kb` 问答页、`#/kb/docs` 文档/导入/审核页、`#/kb/docs/{doc_id}` 详情页；管理员可见版本历史与恢复。

### 5. 数据与接口

- schema 24 新增 11 张 KB 表：`kb_documents`、`kb_cases`、`kb_case_tags`、`kb_import_jobs`、`kb_import_files`、`kb_drafts`、`kb_doc_versions`、`kb_query_logs`、`kb_feedback`、`kb_index_meta`、`kb_terms`。
- REST 路由由 168 条增至 194 条；新增 26 条 KB 路由。
- 备份需同时包含 `data/`（数据库、`data/kb/` 附件与索引）；回滚见部署手册。

## 新增配置

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `kb_enabled` | true | 故障知识库总开关 |
| `kb_answer_role` | assistant | 问答模型角色 |
| `kb_vision_model` | 空 | 预留视觉模型；当前图片仍走人工队列 |
| `kb_top_k` | 6 | 返回案例上限 |
| `kb_no_answer_threshold` | 0.18 | 无答案阈值 |
| `kb_mask_pii` | true | 导入前脱敏 |
| `kb_auto_approve_admin` | true | 管理员直接生效；图片/扫描件不受影响 |
| `kb_max_file_mb` | 50 | 单文件上限 |
| `kb_max_batch_mb` | 200 | 单批上限 |
| `kb_index_max_cases` | 20000 | 索引案例上限 |
| `kb_semantic_enabled` | false | 预留语义通道 |
| `kb_rate_per_min` | 20 | 每用户每分钟问答/检索上限 |

## 升级

1. 备份 `data/` 与当前安装目录。
2. 解压 1.30.0 离线包，执行 `sudo bash bbu-fault-platform/deploy/install_offline.sh --port 8080`（已部署实例使用 `upgrade_offline.sh`）。
3. 启动后 `init_schema()` 幂等创建 schema 24 的 KB 表，不改旧表结构；管理端“系统信息”应显示 schema 24、版本 1.30.0。
4. 管理员进入「故障知识库 → 文档与导入」可先载入 20 条脱敏示例，确认索引状态 ready 后再导入真实数据。

## 已知边界

- 当前不内置 OCR、图片视觉转写或复杂 PDF 版面还原；图片/扫描 PDF 只进人工转写队列。`kb_vision_model` 为后续接入预留。
- 当前未实现 300 条专家金标准、Recall/MRR 评测页、知识图谱/术语后台；真实 2268 条 CSV 语料的 Recall@5 验收未在本机执行，示例数据只用于功能验证。
- 导出的相似标题/近重复处理仍以文件 SHA 和标题 SimHash 检索为主，未实现自动合并向导。

# BBU FaultScope 1.24.6 版本说明（个人模型弹窗重复叠层修复）

1.24.6 修复“个人模型配置（公司内网 MaaS）”弹窗连续点击后出现多层实例、需要多次点击关闭的问题；数据库 schema 保持 **21**。

## 一、现象与根因

- 现象：点击“配置个人 Key”后，如果接口返回前又点了一次，弹窗会叠出多份完全相同的实例；每次点击“关闭”只移除最上层，看起来要连续点很多下。
- 根因：`openPersonalModelModal()` 先 `await /api/profile/model-key`，弹窗要等接口返回后才创建。异步等待期间重复触发没有互斥保护，每次点击都会各自发起请求并在返回后创建一个新弹窗。
- 复现：在同一个任务内同步触发三次入口点击，旧版本会产生 3 个 `.modal-mask`，关闭三次才清空。

## 二、修复

- **打开互斥**：增加 `personalModalState`，从 `loading` 到 `open` 全程只允许一个实例；接口失败时复位为 `idle`，不会卡死入口。
- **关闭复位**：弹窗 `onClose` 统一把状态复位；保存、清除、X、Esc、遮罩关闭都能再次打开。
- **关闭事件加固**：底部“关闭”改为捕获阶段处理，`preventDefault` + `stopPropagation`，一次点击立即销毁当前弹窗，避免按钮内部子节点或页面冒泡影响。
- 不改变个人 Key 的保存、测试连接与清除流程。

## 三、验证

- 新增 `tests/ui_personal_model_modal_smoke.py`：同步连点三次只生成 1 个弹窗；底部关闭、右上角 X、点击遮罩、Esc 各一次即关闭。
- 全量单元/集成测试：**222 passed**。
- REST 全量冒烟：**152/152**。
- 1.24.6 安装包健康返回 `1.24.6`，schema 21；1.24.5 → 1.24.6 升级成功，schema 保持 21。

## 四、升级说明

从 1.24.5 升级到 1.24.6：

- 版本号 1.24.6；离线更新包 `bbu-fault-platform-1.24.6-offline.tar.gz`。
- schema 保持 21；无数据库迁移，仅前端弹窗生命周期修复。

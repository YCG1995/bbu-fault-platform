# 版本说明 1.11.0

发布日期：2026-11-25

1.11.0 集中处理页面导航、空间治理、工坊回退修改和组织信息同步，数据库 schema 保持 10，REST 接口新增一个草稿删除路由。

## 一、系统信息标签页

系统信息拆为五个标签页：

- 概览：运行环境、并发与预算、公开配置；
- 运行参数：在线编辑并保存/重启；
- 任务空间：统计和释放；
- 迁移：工作目录与迁移包；
- 升级：离线包上传、预检、执行与回滚。

首次进入只加载概览；运行参数、任务空间、迁移和升级在首次点击对应标签时再请求，减少首屏等待。标签栏在桌面端吸顶，移动端自动改为横向滚动。

## 二、任务空间支持释放解压文件

`POST /api/tasks/{id}/release` 新增可选请求体：

```json
{ "mode": "raw_inputs" }
{ "mode": "extracted" }
{ "mode": "both" }
```

也兼容 `{ "targets": ["raw_inputs", "extracted"] }`。不传时仍按 `raw_inputs` 处理。

- `extracted`：只删除 `tasks/<task_id>/skills/*/unpacked` 和任务根下的 `unpacked` 目录；报告、证据、案例、数据库记录保留。重跑会从原始日志重新解压。
- `raw_inputs`：沿用原逻辑，扫描所有任务引用，共享文件只有最后一个引用释放时才删除；释放后该任务不能重跑。
- `both`：同时释放两类数据；若其中一类已不可释放，会自动降级为另一类。

概览新增字段：`extracted_bytes`、`retained_bytes`、`can_release_extracted`、`extracted_dirs`。页面可按单任务释放解压文件，也可批量选择「解压文件 / 原始输入 / 两者」。

## 三、技能工坊五个标签页

工坊详情由长页面改为五个标签：

1. 资料输入：可修改原文并保存后重新分析；
2. AI 解析与命名：查看质量、补充或纠正后重建；
3. 规则审查：查看规则表达式、校验结构、确认待验证规则；
4. 案例回归：上传正例/反例并执行构建；
5. 构建发布：查看构建输出、高级 YAML、发布。

标签显示完成状态，可随时返回前面的步骤。修改原文会清空 `analysis_json`、`check_json`、`build_json`，强制重新分析。重新分析、补充重建、规则确认、案例增删和 Profile 手工修改也会统一清空 `build_json` 与旧版本号，避免第 5 步沿用旧的 `verified=true` 结论。后台任务完成后自动跳到对应步骤：分析完成到第 2 步，构建完成到第 5 步。

## 四、草稿删除

新增：

```text
DELETE /api/workshop/drafts/{id}
```

- 删除 `workshop_drafts` 记录、关联 `workshop_jobs` 记录和 `data/workshop/<id>` 工作目录；
- 有 `queued` / `running` 后台任务时拒绝删除；
- 已发布草稿只删除草稿记录，已发布技能和版本记录不删除、不回滚；
- 需要草稿 owner 或管理员权限，并经过 CSRF 校验。

## 五、备份排除原始与解压数据

`deploy/backup.sh` 默认不再打包：

- `data/uploads`、`data/workshop/*/job_uploads` 等原始上传/暂存；
- `data/workshop/*/logs`、`data/workshop/*/extracted`；
- `data/tasks/*/skills/*/unpacked`、`*_unpacked`、`*.extracted`；
- `data/real_logs`、`data/real_cases*/*/input`、`cases/*/*/input`；
- `data/tmp` 等运行临时目录。

仍保留：数据库快照、`data/master.key`、任务报告/证据、技能、案例定义、工坊草稿 YAML。恢复后历史报告可查看，但被排除的原始日志/案例输入需要重新上传才能重跑。

## 六、班组 / 站点同步

用户管理「编辑」弹窗新增班组、站点字段，保存后写入 `users.team` / `users.site`。个人中心每次打开都重新请求 `/api/profile`，显示最新值；字段由管理员维护，个人中心只读。

## 七、验证

- 单元测试：88/88；
- HTTP 全量 REST 冒烟：106/106；
- 浏览器验证：系统信息五个标签页可切换；工坊五个标签页可前进/后退；个人中心显示更新后的班组/站点；
- 备份排除验证：原始上传、任务解压、工坊日志/解压、案例输入和现场日志均未进入归档，报告与案例定义保留。

## 八、升级

1.10.x 可直接用离线更新包升级，schema 不变。升级前仍建议保留一次完整状态备份；若使用 `backup.sh`，恢复后需要重新上传被排除的原始日志才能重跑旧任务。

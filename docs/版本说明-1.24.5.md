# BBU FaultScope 1.24.5 版本说明（MCP 客户端配置布局）

1.24.5 优化“系统信息 → MCP / 助手”页面的客户端配置区域；数据库 schema 保持 **21**，MCP 接口和 Token 流程不变。

## 一、问题

原客户端配置区域使用一个默认宽度的 `<textarea>`：

- 浏览器默认 textarea 只有约 20 个字符宽，1427px 页面上配置代码被挤在左侧窄条里，出现横向和纵向滚动条；
- 全宽蓝色提示独占一行，复制按钮压在代码框下方，右侧留下大片空白；
- 缺少“复制、写入客户端、重启验证”的操作步骤，首次接入时需要自行猜测。

## 二、调整

- **左右分区**：左侧放 read 模式说明、三步接入步骤（复制配置 → 写入 `mcpServers` → 重启验证）和 Token 轮换提示；右侧放可读的代码面板。
- **代码面板**：用带 `mcp.json / JSON` 标题栏的 `<pre><code>` 代替 textarea，配置代码完整展开、可选中、超长行自动换行；复制入口移到面板右上角。
- **复制行为**：复制按钮直接读取代码面板文本，仍复制带 `<YOUR_TOKEN>` 占位的完整 JSON，不复制页面实体编码。
- **响应式**：≤900px 时说明与代码上下排列；≤640px 代码字号缩小、标题栏换行，390px 无横向溢出。

## 三、验证

- 新增 `tests/ui_mcp_smoke.py`：配置分区、代码面板、复制 JSON 到剪贴板、390px 无横向溢出，页面无 JS 错误。
- 既有单元/集成测试：**222 passed**。
- REST 全量冒烟：**152/152**。
- 1.24.5 离线包安装后健康返回 `1.24.5`，schema 21；1.24.4 → 1.24.5 升级成功，schema 保持 21。

## 四、升级说明

从 1.24.4 升级到 1.24.5：

- 版本号 1.24.5；离线更新包 `bbu-fault-platform-1.24.5-offline.tar.gz`。
- schema 保持 21；无数据库迁移。
- 升级前仍建议备份数据库与运行数据。

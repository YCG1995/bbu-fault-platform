# BBU FaultScope 1.21.0 版本说明（管理与诊断体验 / 工坊重构 / 证据增强）

发布日期：2026-11-26

本版本按四阶段计划完成：M1 阻断修复、M2 管理与诊断体验、M3 技能工坊重构、M4 证据与智能化增强。数据库 schema 从 17 升到 18，新增按用户隔离的 `mcp_tokens` 表。

## 一、M1 阻断修复

- 运行参数保存不再把 enum 当成整数，布尔/浮点/整数/字符串分别收集。
- 全局弹窗仅在 `pointerdown` 与 `pointerup` 都落在遮罩本身时关闭，输入框拖选不会误关。
- 工坊规则确认同步更新 profile、`analysis.intake.evidence_rules`、质量计数、`check.quality`、`status` 与 `last_error`，并失效旧构建。
- 待确认规则以后端 `check.unverified_rules` 为唯一权威；错误卡片可定位到具体规则。
- AI 建议去重，步骤与门禁状态统一派生。

## 二、M2 管理与诊断

- 所有用户都能进入“系统信息”查看概览，并管理自己的 MCP Token；运行参数、任务空间、备份、迁移、升级仍只对管理员显示。
- MCP Token 按用户隔离：每个账号独立 Token、独立模式、独立最近使用时间；账号停用后 Token 立即失效。
- 专家拥有工程师的诊断、任务记录、真实案例、技能库、技能工坊入口；复核只对分配给自己的任务开放，且不能复核自己创建的任务。
- 首次登录不再强制修改初始密码，登录后直接进入总览。
- 新建诊断可选择指定技能；指定后只执行所选技能，不自动追加其他技能，也不触发补规划。
- 悬浮助手增加“清空对话”，移除底部固定提示。
- 任务详情证据链长路径折叠为文件名概要，展开后显示完整路径。
- 技能库抽屉增加“用此技能诊断”，直接带到新建诊断并预选该技能。

## 三、M3 技能工坊

- 步骤更名：资料输入、故障解析、规则确认、案例验证、构建发布。
- 移除“领域配方”选择入口，配方仍可被后端兼容读取但不作为前台步骤。
- 规则卡片增加 all_of / any_of / none_of / 数值阈值 / 时间窗 / 已确认标签，并可展开原始规则表达式。
- 案例支持一次多选文件或上传文件夹；多个文件作为同一案例输入，`case.yaml` 使用 `input` 目录。
- 案例术语统一为“故障案例 / 正常案例”。
- 后台任务增加历史详情表：类型、状态、阶段、进度、更新时间、错误。
- 步骤完成状态与“当前下一步”由同一套状态派生，避免确认后仍提示未确认。

## 四、M4 证据与智能化增强

- 恢复验证支持上传真实证据文件，记录文件名、大小、SHA256，并自动抽取前 60 行作为证据摘要。
- 工坊规则支持“用现有日志试跑”：按当前 profile 生成临时证据规则，对已解压日志只读执行 `search_evidence.py`，返回命中规则、文件与片段。
- 归档支持 zip / tar / tar.gz / gz / bz2 / xz / zst / 7z；zstd 与 7z 优先使用 Python 解码器，缺失时回退系统命令。
- 助手知识库沿用 1.20.3 的 BM25F、意图路由与多轮改写，不引入向量方案。

## 五、升级说明

从 1.20.3 升级到 1.21.0 会执行 schema 18 迁移，新增 `mcp_tokens` 表；旧全局 MCP Token 不再参与鉴权，用户需要在“系统信息 → MCP / 助手”重新生成个人 Token。

```bash
sha256sum -c bbu-fault-platform-1.21.0-offline.tar.gz.sha256
tar -xzf bbu-fault-platform-1.21.0-offline.tar.gz
sudo bash bbu-fault-platform/deploy/upgrade_offline.sh \
  --package /path/to/bbu-fault-platform-1.21.0-offline.tar.gz
```

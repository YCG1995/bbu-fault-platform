# BBU 故障诊断平台 1.28.1 版本说明

发布日期：2026-11-27

## 变更

- `model_discovery_allow_private` 默认值由 `false` 改为 `true`。
- 默认允许模型发现访问私网与回环地址，适配现场私有 MaaS / 本地推理网关。
- 元数据地址（`169.254.169.254`）与 IPv6 link-local（`fe80::/10`）仍然永久拒绝，不受该开关影响。
- 仍可通过 `BBU_MODEL_DISCOVERY_ALLOW_PRIVATE=0` 恢复“默认拒绝私网”的严格策略。

## 影响

- 新建或未显式配置该开关的实例，模型“获取模型列表”可直接访问私网地址，无需再加环境变量。
- 出站重定向仍逐跳校验，跨主机仍剥离 `Authorization`、`x-api-key` 与 `Cookie`。
- 响应体 1 MB 上限、JSON Content-Type 校验、3 跳限制保持不变。

## 验证

- `tests/test_netguard.py` 新增 3 项默认策略测试：默认允许回环、显式关闭仍拒绝、默认仍拒绝元数据与 link-local。
- 全量 pytest 与 REST 162/162 冒烟回归。

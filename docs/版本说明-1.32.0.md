# BBU 故障诊断平台 1.32.0 版本说明

1.32.0 是 1.31.0 之后的第一波增强，聚焦知识库灾备、恢复一致性和服务端边界。数据库 schema 保持 **26**，不新增表/列；REST 路由由 220 增至 **222**；仍为单个 Linux 离线包。

## 本版变更

### 1. 备份 v3：附件与导入任务一起备份

- 备份包版本升到 `version=3`；在 v2 的 7 个 JSONL 之外新增：
  - `import_jobs.jsonl`：导入任务；
  - `import_files.jsonl`：文件行、SHA256、文档/草稿关联与 `present` 标记；
  - `files/<sha256>`：原始上传附件字节。
- `manifest.json` 新增 `import_jobs`、`import_files`、`files`、`file_bytes`、`missing_files` 计数，以及 `files_checksum`；原有 `file_sha256` 和总 `checksum` 仍覆盖全部 JSONL。
- 备份时按 `kb_import_files.sha256` 重新校验附件；附件缺失只记录 `missing_files`，附件内容与数据库 SHA 不一致则拒绝备份，避免生成“看似成功、实际损坏”的包。
- 恢复 v3 包会把 `kb_import_files.stored_path` 指向新的 `data/kb/files/` 路径，附件下载继续可用；缺失附件对应的文件行标记失败并计数。
- v2 包仍可恢复：没有附件与导入任务时按旧语义处理，向后兼容。

### 2. 恢复单事务与合并去重

- 恢复流程改为单事务：新库创建、文档、案例、修订链、文档版本、草稿、审核、术语、导入任务与附件行全部使用同一个 SQLite 连接和同一次提交。
- 恢复中途任一步失败会整体回滚，不再留下“半个新库”；已写入但未被数据库引用的附件文件会清理。
- 合并到已有库时默认按 `source_sha256` + `content_sha256` 跳过重复文档，返回 `skipped_duplicates`、`skipped_cases`，不覆盖已有文档和修订链。需要强制全量导入时可通过恢复接口的 `dedupe=0` 关闭。
- 同一备份包重复合并到同一目标库，第二次导入文档数为 0，不会形成重复案例。

### 3. 服务端边界

- 跨库检索在服务端强制 `MAX_CROSS_LIBRARIES=5`；超过 5 个不同知识库返回 400 `too_many_libraries`，不再只依赖前端拦截。
- 新增批量审核接口，单批最多 50 条，逐条返回成功/失败结果：
  - `POST /api/kb/reviews/batch-decision`，请求体 `{ids:[...], decision:"approve|reject|adopt_patch", note, apply_patch}`；
  - `POST /api/kb/reviews/batch-retry`，请求体 `{ids:[...]}`。
- 知识库页面的批量通过/驳回/重试改为一次请求，不再逐条循环调用单条接口；部分失败时保留成功项并提示失败数量。

### 4. 助手案例可见性

- `KBService.get_case` 增加可选 `user` 参数；非管理员读取仅管理员可见库的案例时按 404 处理，不泄露存在性。
- 平台助手 `get_fault_case` 传入当前用户；REST 案例详情同时使用服务层校验，保留原有 `_kb_require_visible` 入口。

### 5. 版本与清单

- `bbu/__init__.py` 升到 `1.32.0`；schema 仍为 26，无迁移。
- REST 清单更新为 222 条；UI actions 仍为 140。
- 新增 `tests/test_kb_first_wave_132.py`，覆盖备份 v3 附件、原子恢复、合并去重、5 库上限和案例可见性。

## 升级与回滚

1. 升级前备份 `/var/lib/bbu-fault-platform`，至少包含 `data/`、`master.key`、`config.json`。
2. 解压 `bbu-fault-platform-1.32.0-offline.tar.gz`，执行 `deploy/upgrade_offline.sh`；schema 保持 26，无需迁移。
3. 升级后检查「系统信息」版本为 `1.32.0`，并抽查备份/恢复、附件下载和跨库检索。
4. 回滚保留 1.31.0 离线包和升级前 `data/` 快照。旧代码可读取 schema 26；但恢复 v3 包前应确认目标版本不低于 1.32.0。

## 已知边界

- 本版不包含 OCR、真语义向量、术语后台、评测台、近重复合并向导、批量导出报告和 Windows 运行时；这些属于后续波次。
- v3 备份默认包含附件，包体可能明显大于 v2；备份生成仍在内存中组包，超大库建议直接备份整个 `data/` 目录作为兜底。
- 合并去重是精确 SHA 去重，不做标题/文本相似度合并；近似重复仍需后续向导。
- 恢复只还原备份中存在的导入任务与文件行；已经物理清理的附件无法从备份包之外恢复。
- 1.30.5 及以前的旧导入任务仍不可回退，只支持删除记录；本版未改变该语义。

# BBU 故障诊断平台 1.30.3 版本说明

本版把「系统信息」收进管理导航，并在总览增加系统资源面板；数据库 schema 保持 25，REST 路由保持 211 条，不新增接口。

## 1. 导航

- 左侧「诊断」分区移除「系统信息」。
- 「管理」分区新增「系统信息」，排在「用户管理」之后、「审计日志」之前；管理员可直接看到系统路径、并发、运行配置、升级、备份、迁移与 MCP。
- 普通用户不再从主诊断导航进入系统信息；已有 `#/system` 深链仍按原权限展示可用分区。

## 2. 总览系统资源

总览在顶部四个任务统计下方新增「系统资源」卡片，展示：

- **CPU 使用率**：系统总 CPU 使用率、核数、1 分钟负载与采样来源；
- **当前应用内存**：平台进程 RSS、总内存和占比、线程数；
- **系统内存**：已用/总量/可用与使用率；
- **数据盘**：平台数据目录所在磁盘的已用/可用/总量与使用率。

卡片支持「刷新」，管理员可跳转「系统信息」。采样数据来自新增的 `bbu/system_metrics.py`，仅用标准库：

- Linux 读取 `/proc/stat`、`/proc/meminfo`、`/proc/self/status`；
- Windows 使用 `GetSystemTimes`、`GlobalMemoryStatusEx`、`GetProcessMemoryInfo`；
- 其它平台返回可用子集，不会因为单个指标不可读影响 `/api/stats` 或 `/api/system/info`。

## 3. 接口

- `GET /api/stats` 新增 `system` 字段：`cpu`、`memory`、`process`、`disk`。
- `GET /api/system/info` 新增同结构 `system` 字段。
- 采样结果在进程内缓存 1.2 秒；首次采样最多增加约 60 ms，之后走缓存。系统资源是增强信息，采样异常时返回 `null`/`unavailable`，不影响主业务接口。

## 4. 验证

- `pytest`：380 passed（新增系统资源快照测试）。
- `python3 tests/api_full_smoke.py`：REST 211/211，`/api/stats` 与 `/api/system/info` 均校验 `system` 资源字段。
- `python3 tests/ui_kb_smoke.py`：总览系统资源卡、CPU/应用内存/系统内存/数据盘、系统信息在「管理」导航分组，全部通过。
- 真实知识库 2,268 文档 / 2,762 案例回归保持通过。

## 5. 部署

1. 解压 `bbu-fault-platform-1.30.3-offline.tar.gz`。
2. 已部署实例执行 `sudo bash bbu-fault-platform/deploy/upgrade_offline.sh`；全新安装执行 `install_offline.sh --port 8080`。
3. schema 保持 25，无需额外迁移；升级后「系统信息」显示版本 1.30.3。

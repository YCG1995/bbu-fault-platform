# BBU 故障诊断平台 1.30.1 版本说明

发布日期：2026-11-27

## 主题

本版按《故障查询知识库开发计划 V2》补齐 R6 案例变更记录与 R7 统计、AI 审核，版本从 1.30.0 升至 1.30.1，数据库 schema 从 24 升至 25；继续只交付一个标准 Linux 离线包。

### 1. 案例修订台账（R6）

- 新增 `kb_case_revisions`：`revision/action/actor/source/reason/diff_json/snapshot_z/prev_hash/entry_hash`，`UNIQUE(case_id, revision)`，append-only 触发器拒绝 UPDATE/DELETE。
- 快照用 zlib 压缩；`entry_hash = sha256(prev_hash + snapshot_sha256 + action + actor_type:actor_id:actor_name + created_at)`，单案例可校验整条链。
- 初始导入写 `import`，文档编辑写 `update`，启停写 `status`，恢复写 `restore`，删除写 `delete`；标题-only 编辑不制造空修订，也不清审核结论。
- 单案例 API：时间线、单次修订、字段级 diff、恢复、哈希校验；恢复生成新修订，不删除历史。
- 全局审计：`GET /api/kb/audit`，按操作人/动作/对象/时间筛选，CSV 导出。

### 2. 七组统计（R7）

- 新增 `kb_stats.py`：库存、覆盖、使用、审核、变更、导入、索引；单案例命中/引用/反馈归入“单条知识”。
- 当前真值直接由 SQLite 聚合，另写 `kb_stats_daily` 日快照；趋势覆盖查询、零结果、修订、审核、导入。
- 统计页支持 7/30/90 天、图表条和 CSV；`pending` 包含 queued/running/manual/failed，AI 覆盖率只算模型实际完成的审核。
- 搜索命中累加 `hit_count` 与 `kb_case_usage_daily`，回答引用累加 `citation_count`，反馈按查询日志 `top_ids_json` 累加 helpful/unhelpful。

### 3. AI 预审与人工终审（R7）

- 新增 `kb_review.py`：六维评分（问答匹配 25、原因完整 20、方案可执行 20、实体一致 15、来源忠实 10、安全隐私 10）。
- 问题使用 allowlist（answer_mismatch、multi_cause_merged、missing_cause、thin_cause、missing_solution、thin_solution、entity_mismatch、unsupported_claim、pii_risk、prompt_injection、low_quality、no_prevention、other）。
- 建议 patch 只允许案例字段白名单；内容哈希 + prompt 版本 + 模型做缓存；模型不可用/超时/JSON 不合规转 `manual`，异常转 `failed`，均不阻塞导入。
- 审核状态：`queued/running/done/manual/failed/decided`；人工终审通过/驳回/采纳 patch 后才发布；AI 自动发布默认关闭。
- API：审核列表/详情/创建（支持单条与 `targets` 批量）/运行队列/终审/重试。

### 4. 管理端 9 分区

- `#/kb/docs?tab=...` 支持概览、统计、文档、导入、审核、变更与审计、词典、评测、设置。
- 概览：生效文档/案例、待处理审核、近 30 天查询与修订、索引状态、最近导入/变更。
- 统计：7/30/90 天切换、趋势条、高频问题、被引用案例、覆盖矩阵、审核与变更漏斗、CSV。
- 审核：待入库草稿与 AI/人工审核队列、审核详情弹窗、批量处理、人工终审。
- 文档详情：每个案例的修订/编辑/启停按钮，修订链弹窗显示哈希校验、diff、恢复；案例编辑必须填写原因。

### 5. 数据与接口

- schema 25 新增 7 张表：`kb_case_revisions`、`kb_reviews`、`kb_case_usage_daily`、`kb_stats_daily`、`kb_eval_sets`、`kb_eval_queries`、`kb_eval_runs`；评测表先建好，评测台在 1.31.0 开放。
- `kb_cases` 新增 `revision/review_status/review_score/last_review_id/hit_count/citation_count/last_hit_at/helpful_count/unhelpful_count/updated_by`。
- REST 路由由 194 条增至 210 条，新增 16 条 KB 治理路由；工具仍为 23 个。
- 备份仍只需覆盖 `data/`（数据库、`data/kb/` 附件与索引）。

## 升级

1. 备份 `data/` 与当前安装目录。
2. 解压 1.30.1 离线包，已部署实例执行 `sudo bash bbu-fault-platform/deploy/upgrade_offline.sh`；全新安装执行 `install_offline.sh --port 8080`。
3. 启动后 `init_schema()` 幂等迁移到 schema 25；管理端“系统信息”应显示 schema 25、版本 1.30.1。
4. 管理员进入「故障知识库 → 文档」可先载入示例，再在「变更与审计」确认台账、在「统计」确认七组指标。

## 真实语料验收补记（2026-11-27）

- 语料：用户附件 `故障知识库示例.csv`，2,268 条记录、4,050,795 字节、表头 `question,answer`。
- 第一次真实导入在 1,101 文档 / 1,306 案例处失败：`UNIQUE constraint failed: kb_cases.id`；根因是 `new_id()` 默认仅 6 个十六进制字符，千级案例触发生日碰撞。
- 修复：`new_id(..., entropy=8)` 可选扩展；知识库的 J/F/Q/FB/R/K/D/V/DR、审核 RV 改用 8 字节随机；保留旧 ID 调用格式。
- 复测：同一 HTTP `POST /api/kb/import`（`mode=direct`）全量完成，`done_files=1`、`failed_files=0`；2,268 文档 / 2,762 案例 / 0 草稿；索引 ready，95,833 词、约 9.6 MB、构建 1,561 ms。
- 检索探针：`看门狗复位`、`EPLD 版本不一致`、`过温下电保护`、`NRDC 开站切换 基带板 看门狗`、`UCI_B7 高温环境试验 BPN2 过温` 首条均命中相关案例；同时修复了通道补位用 0.01 低分项污染首条排序的问题。
- 统计：覆盖字段 cause 84.47% / solution 93.19%；质量分 80–100 为 2,018 案、60–79 为 180 案、0–59 为 70 案。
- 边界：上述语料没有逐条专家 expected/excluded 标签，不能据此计算现网准确率；“火星探测器电池故障”这类“域外主体 + 领域词”查询仍可能召回电池柜案例，需靠后续词典/评测集校准拒答。

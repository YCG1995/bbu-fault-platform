# 故障知识库评测报告（1.30.0）

评测日期：2026-11-27  
数据：`examples/kb/故障知识库示例-脱敏.csv`（20 条文档、21 个案例）  
性质：**功能与回归冒烟，不是专家金标准验收**。真实 2268 条 CSV 未随本轮任务提供，不能据此宣称生产 Recall 指标。

## 1. 测试方法

- 用临时数据目录构造 `KBService(start_worker=False)`，导入示例 CSV 后显式 `rebuild_index()`。
- 取 12 条代表性问法，人工指定一个必须出现在标题中的实体词；检查该词是否出现在 top-1 / top-5 标题。
- 另取 2 条库外问题检查拒答。
- 单线程、同一进程、20 个案例规模；延迟只代表示例规模，不代表 2268/10k 容量。

问法：

`看门狗复位`、`1588 时钟失锁`、`SSD 只读`、`电源掉电`、`SFP 收光低`、`EPLD 升级失败`、`内存泄漏`、`风扇转速异常`、`GNSS 失锁`、`License 容量不足`、`单板反复重启`、`VBPE2 业务中断`。

## 2. 结果

| 指标 | 结果 |
| --- | ---: |
| 示例文档 / 案例 | 20 / 21 |
| top-1 标题命中 | 12 / 12 |
| top-5 标题命中 | 12 / 12 |
| 平均检索延迟 | 3.5 ms |
| P95 检索延迟 | 3.7 ms |
| 最大检索延迟 | 4.2 ms |
| 库外问题拒答 | 2 / 2（`今天天气怎么样`、`如何办理护照`） |

## 3. 解释与边界

- 这 12 条问法与示例标题高度接近，属于“同题/实体精确”冒烟，不能代表口语改写、跨术语、症状描述或 2268 条真实语料。
- 20 个案例的延迟没有容量参考价值；计划中的 2268/10k 指标必须在真实语料上重跑。
- 示例 CSV 已脱敏；真实 CSV 若包含姓名+工号，导入时应保持 `kb_mask_pii=true`，并在验收中抽查原文/索引/普通用户响应三处是否都不含 PII。
- 无答案只验证了两个明显库外问题，不能证明无答案准确率 ≥90%。

## 4. 后续验收建议

1. 用真实 2268 条 CSV 导入，记录文档数、案例数、跳过/失败数、构建时间、RSS 与索引大小。
2. 建立 300 条专家金标准（含实体精确、症状描述、开放改写、无答案四类），按计划门槛计算 Recall@1/5/10、MRR@10、无答案准确率与引用有效率。
3. 对 396 条多根因记录抽查派生案例是否可独立引用，避免一个根因被另一个根因稀释。
4. 用真实模型跑问答，统计降级率、非法引用回退率、P95 端到端延迟；无模型路径单独保留基线。

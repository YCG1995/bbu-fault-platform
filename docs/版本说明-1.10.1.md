# 版本说明 1.10.1

> 后续补丁：1.10.2 修复技能工坊等页面加载时内联 SVG 无尺寸约束、显示巨大 Flask/刷新图标的问题，详见 `docs/版本说明-1.10.2.md`。

基线：1.10.0（schema 10）→ 1.10.1（schema 10）
日期：2026-11-25

## 一、本版定位

1.10.1 是 1.10.0 的补丁版本，不新增功能、不改数据库 schema、不改 REST 契约，只修复现场升级和浏览器图标相关问题。已经安装 1.10.0 的实例可以直接覆盖升级；从 1.8.0/1.9.0 升级仍按 1.10.0 的迁移路径执行。

## 二、修复内容

### 1. 浏览器标签页的旧 Flask favicon 缓存

- 新增 `web/favicon.ico`，使用平台品牌波形图标，不再依赖缺失的 `/favicon.ico`。
- `web/index.html` 同时声明 ICO 与 SVG，并加 `?v=1.10.1` 版本参数，强制浏览器刷新旧网站图标缓存。
- `bbu/httpd.py` 的静态文件回退改为：只有前端路由缺失时才回退 `index.html`；`/assets/*`、带扩展名的路径和 `/favicon.ico` 缺失时返回 404，避免把 HTML 当作图标或脚本返回。
- 该图标是浏览器历史缓存中的 Flask 图标，不是平台运行 Flask，也不是前端业务图标。

### 2. 备份脚本在 Ubuntu 16.04 上 SyntaxError

- `deploy/backup.sh` 不再把系统 `python3` 作为默认解释器；优先查找 `/opt/bbu-python313/bin/python3.13`、`/opt/bbu-python313/bin/python3`、`/opt/python3.13/bin/python3` 等内置运行时。
- 备份脚本启动时校验 Python ≥ 3.7（`sqlite3.Connection.backup` 的最低要求）；低于该版本直接输出实际解释器和修复提示，不再抛出难懂的 `<stdin>` 语法错误。
- 去掉内嵌 Python 的 f-string，避免在旧解释器上先触发语法错误。
- `deploy/upgrade_offline.sh` 调用备份脚本时显式传递 `PYTHON_BIN`，确保一键包和自定义 Python 前缀走同一个解释器。

## 三、验证

- 单元测试 83/83 通过；HTTP 全量冒烟 105/105 通过。
- `/favicon.ico` 返回 `image/vnd.microsoft.icon`，内容为 ICO 文件头；`/assets/<不存在>` 返回 404；不存在的前端路由仍返回 `index.html`。
- 使用 Python 3.13/3.12 执行备份脚本成功生成 state tar，数据库快照可读取。
- 1.8.0 → 1.10.x 的 schema 8 → 10 迁移路径不变；1.10.0 → 1.10.1 不触发数据库迁移。

## 五、升级提示

- 网页上传仍要求服务账号对 `/var/lib/bbu-fault-platform/updates` 有写权限。遇到 `.web.lock: Permission denied` 时先修复该目录所有权，或直接使用 `upgrade_offline.sh` 以 root 执行离线升级。
- 从 1.8.0 一键包升级时，若平台使用 `/opt/python3.13/bin/python3`，可在离线升级命令中显式指定：

```bash
sudo env PYTHON_BIN=/opt/python3.13/bin/python3 \
  bash /tmp/bbu-fault-platform/deploy/upgrade_offline.sh
```

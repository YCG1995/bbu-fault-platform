# 技能工坊十场景测试报告

日期：2026-11-26  
范围：`bbu/workshop.py`、`bbu/workshop_spec.py`、工坊草稿/构建/发布链路  
环境：Linux 临时目录，独立 SQLite、独立技能/案例目录；未读写主实例数据，未调用真实模型。

## 结论

构造并执行 **10 个不同场景，10/10 通过**。测试过程中发现并修复 2 个通用解析缺陷：

1. **小数阈值被误拆成编号列表**：`VOLT_12V 低于 10.5` 被拆成 `VOLT_12V 低于`、`1`、`5`，导致阈值无法解析。
2. **阈值数值被误当版本号**：`10.5` 被写入 `version_scope`，造成阈值元数据污染。

修复后，十场景、工坊单元测试、三配方回归、全量 Python 测试和 REST 冒烟均通过。

## 修复内容

### 1. 小数阈值列表拆分

文件：`bbu/workshop_spec.py` 的 `_list()`

```python
# 修复前
parts = re.split(r"(?=\d+\s*[、.]\s*)", line)

# 修复后
parts = re.split(r"(?=\d+\s*[、.](?!\d)\s*)", line)
```

`10.5` 中的 `.` 后面仍是数字，不再被当作“1. …”列表标记。

### 2. 阈值版本范围误判

文件：`bbu/workshop_spec.py` 的 `parse_thresholds()`

版本号提取改为必须有 `V/v` 前缀或“版本”上下文，不再把阈值本身 `10.5` 识别为版本范围。

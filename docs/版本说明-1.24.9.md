# 版本说明 1.24.9（H0 安全热修）

## 变更

- 新增统一出站 URL 安全策略 `bbu/netguard.py`：
  - 默认拒绝私网、环回、link-local、云元数据、保留、组播、未指定地址；
  - `model_discovery_allow_private=true` 可显式允许私有/环回 MaaS，但元数据与 link-local 永不放行；
  - 重定向最多 3 跳，每跳重新校验；跨主机重定向剥离 `Authorization`、`x-api-key`、`Cookie` 等认证头；
  - 响应体默认 1 MB 上限，超出返回 413；模型列表要求 JSON Content-Type；
  - 模型发现与模型推理共用同一套校验，避免只挡发现、不挡推理。
- `POST /api/models/discover` 错误映射：400 参数/域名解析、403 安全策略、413 响应超限、502 上游错误、504 超时。
- 审计只记录 `base_url_host` / `base_url_path`，不记录 API Key。
- 新增配置：
  - `model_discovery_allow_private`（默认 `false`）
  - `model_request_max_bytes`（默认 `1048576`）

## 测试

- `tests/test_netguard.py`：16 项，覆盖私网/元数据/协议/重定向/跨主机认证头/响应上限/超时/401/500。
- 全量 pytest：244 passed（含 1.24.8 基线 228 项与 H0 新增 16 项）。

## 风险与边界

- DNS 解析与 urllib 连接之间存在理论上的 DNS rebinding 窗口；本版通过每跳重校验降低风险，未实现 pinned-IP 连接。
- 私有 MaaS 必须显式开启 `model_discovery_allow_private`；公网模型保持默认拒绝。

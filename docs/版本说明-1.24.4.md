# BBU FaultScope 1.24.4 版本说明（迁移页覆盖恢复布局）

1.24.4 优化“系统信息 → 迁移”页面的覆盖恢复区域与迁移记录空态；数据库 schema 保持 **21**，迁移接口与风险流程不变。

## 一、问题

原覆盖恢复区在一个橙色卡片里从上到下堆叠：

- 迁移包使用浏览器原生文件输入，显示为 `Choose File` / `No file chosen`，与应用视觉不一致，也无法显示包大小；
- 迁移口令、确认口令和文件选择混用不同的栅格，确认口令单独占满整行，右侧留出大片空白；
- 上传按钮在卡片右下角，容易被右下角悬浮助手遮挡；
- “迁移记录”为空时只有一行居中的“暂无迁移任务”，缺少说明与下一步信息。

## 二、调整

- **危险区左右分区**：左侧集中展示“覆盖恢复 / 高风险”、覆盖范围、备份位置、健康检查回滚和“建议先测试验证”的提示；右侧集中放置导入表单。
- **自定义迁移包选择**：隐藏原生文件输入，改为可点击的拖放区样式；选中后显示文件名与包大小，点击可重新选择。桌面保留“浏览文件”入口，移动端整块可点。
- **口令与操作对齐**：迁移口令和确认口令在桌面并排，移动端单列；上传按钮与状态文案同一行，并向右留出悬浮助手的安全间距。
- **迁移记录空态**：标题旁显示保留规则，空态改为带图标的说明卡，明确导出、切换和恢复任务会在这里出现。
- **移动端**：覆盖恢复分区、表单和记录均单列，390px 无横向溢出。

## 三、验证

- 新增 `tests/ui_migration_smoke.py`：覆盖恢复分区、自定义迁移包选择（真实文件选择器）、记录空态、390px 无横向溢出，页面无 JS 错误。
- 既有单元/集成测试：**222 passed**。
- REST 全量冒烟：**152/152**。
- 1.24.4 离线包安装后健康返回 `1.24.4`，schema 21；1.24.3 → 1.24.4 升级成功，schema 保持 21。

## 四、升级说明

从 1.24.3 升级到 1.24.4：

- 版本号 1.24.4；离线更新包 `bbu-fault-platform-1.24.4-offline.tar.gz`。
- schema 保持 21；无数据库迁移。
- 升级前仍建议备份数据库与运行数据。

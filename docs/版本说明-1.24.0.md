# BBU FaultScope 1.24.0 版本说明（用户每日用量）

1.24.0 在 1.23.0 用量统计基础上补充“每个用户每天的使用次数和总量”。数据库 schema 保持 **21**，不新增表或迁移。

## 一、统计口径

- `user_daily` 按本地时区日期（`local_tz_offset`）聚合每个用户当天实际发生的模型调用。
- 每条用户日记录包含：`calls`、`failed_calls`、`input_tokens`、`output_tokens`、`total_tokens`，以及用户 ID 与显示名。
- 管理员查看全部用户时返回所有在统计窗口内有调用的用户；管理员指定 `user_id` 时只返回该用户；普通用户强制只返回自己。
- 用户汇总由每日记录派生：活跃天数、调用次数、失败、输入/输出/总 Token、日均调用、日均 Token。

## 二、接口变化

`GET /api/usage/overview` 返回结构新增：

```json
{
  "user_daily": [
    {
      "date": "2026-11-26",
      "calls": 6,
      "failed_calls": 0,
      "total_tokens": 1432,
      "users": [
        {
          "user_id": 2,
          "user_name": "现场工程师",
          "calls": 6,
          "failed_calls": 0,
          "input_tokens": 1040,
          "output_tokens": 392,
          "total_tokens": 1432
        }
      ]
    }
  ]
}
```

`user_daily` 只包含有调用的日期，按日期升序；没有调用的日期不出现在列表中。`daily`（模型每日）、`models`、`skills`、`users` 等原有字段保持不变，向后兼容。

## 三、页面变化

“用量统计”页新增“用户每日用量”卡片：

- 汇总表：用户、活跃天数、调用、失败、输入/输出/总 Token、日均调用、日均 Token；
- 每日明细：默认折叠，点击展开后按日期倒序展示每天每个用户的调用、失败与 Token；
- 管理员仍可通过顶部用户下拉只看指定用户；普通用户仍只显示“仅显示我的调用记录”，无用户下拉。

## 四、权限与边界

- 普通用户请求 `user_id=他人` 返回 **403**；`user_id` 非整数返回 **400**。
- 1.23.0 之前的历史调用没有逐调用事件，`user_daily` 无法回填；任务 Token 表仍按 `tasks.stats_json` 回退并标记“历史汇总”。
- 助手与工坊调用按实际用户归属进入 `user_daily`，但不属于诊断任务，因此不会出现在“任务 Token”表。

## 五、升级说明

从 1.23.0 升级到 1.24.0：

- 版本号 1.24.0；离线更新包 `bbu-fault-platform-1.24.0-offline.tar.gz`。
- schema 保持 21；`llm_usage_events` 表与索引不变，无数据库迁移。
- 升级前仍建议备份数据库与运行数据。

## 六、验证基线

- Python 单元/集成测试：**222 passed**（新增用户每日聚合断言，未增加测试函数）。
- REST 全量冒烟：**152/152** 路由覆盖通过，`overview` 断言包含 `user_daily`。

- 离线安装/升级：1.24.0 包健康返回 `1.24.0`，schema 21；1.23.0 → 1.24.0 升级 schema 保持 21。

# BBU FaultScope 1.23.0 版本说明（用量统计）

1.23.0 在 1.22.0 基础上新增“用量统计”：按日查看各模型使用量（带堆叠柱图）、逐任务 Token 消耗、各技能执行消耗。个人 MaaS API 与管理员共享模型分开统计；管理员可查看全部用户，普通用户只能查看自己的调用。数据库 schema 从 20 升到 **21**。

## 一、数据模型

新增 `llm_usage_events` 表，一条记录对应一次实际模型调用尝试：

- 归属：`user_id`、`task_id`、`task_kind`（`diagnosis` / `workshop` / `assistant` / `direct`）、`skill_name`；
- 模型：`model_id`、`model_name`、`provider`、`model`、`scope`（`admin` 共享 / `personal` 个人）；
- 用途：`purpose`、`stage`；
- 结果：`status`、`input_tokens`、`output_tokens`、`total_tokens`、`estimated_input_tokens`、`latency_ms`、`error`；
- 时间：`created_at`。

采集挂在 `AIGateway.complete()` 的每次尝试上报点，覆盖规划、补规划、仲裁、报告、JSON 修复和失败重试；失败尝试保留估算输入 Token。统计写库是旁路，异常不会中断诊断主链路。

旧库启动时由 `init_schema()` 的幂等 `CREATE TABLE IF NOT EXISTS` 自动补表与索引，无需手工迁移。

## 二、聚合与接口

新增 `UsageStore`，按本地时区（`local_tz_offset`）切日：

- `GET /api/usage/overview?days=30&user_id=<可选>`：返回 `range` / `totals` / `daily` / `models` / `skills` / `users` / `directory`。`daily` 包含每日模型分层，供图表使用；`models` 同时包含共享与个人来源的汇总；`directory` 是管理员切换用户的全量用户目录。
- `GET /api/usage/tasks?days=30&user_id=<可选>&page=1&page_size=20`：按任务汇总调用、输入/输出/总 Token 与参与模型；逐调用事件按 `task_kind='diagnosis'` 关联，历史任务无事件时回退 `tasks.stats_json` 并标记 `has_events=false`。
- 管理员不传 `user_id` 看全部，传则看指定用户；普通用户只能看自己，显式传他人 `user_id` 返回 **403**；`days` 超出 1–365 返回 **400**。

## 三、页面

侧边导航新增“用量统计”，默认近 30 天，支持 7 / 30 / 90 天切换：

- 顶部指标：模型调用、Token、覆盖任务、活跃用户（普通用户显示执行技能数）；
- 每日模型使用：内联 SVG 堆叠柱图，可在 Token / 调用次数之间切换，附模型图例；
- 模型明细：共享与个人标记、调用/失败、输入/输出/总 Token、用户数、平均耗时；
- 每日明细：按日调用、Token 与模型分布，点击展开；
- 技能消耗：执行、失败、任务数、Token、工具调用、证据、关联输入、平均耗时、最近执行；
- 任务 Token：任务链接、用户（管理员可见）、状态、调用、输入/输出/总 Token、参与模型；无逐调用事件的历史任务显示“历史汇总”。

管理员额外显示用户下拉；普通用户只显示“仅显示我的调用记录”。

## 四、已知边界

- 1.23.0 之前的历史任务没有逐调用事件，任务表回退任务汇总值；历史任务的“每日模型归属”无法回填，模型每日图只从本版本上线后的调用开始统计。
- 技能 Token 优先取技能执行 `stats_json.tokens`；有同名技能的直接模型事件时取两者较大值，避免同一执行重复累计。关联输入按任务去重，同一任务多技能会重复显示该任务输入大小，页面已注明口径。
- 助手调用不绑定诊断任务，计入模型/每日/技能统计，但不出现在“任务 Token”表；工坊任务同理。
- 模型连通性测试调用不计入统计。

## 五、升级说明

从 1.22.0 升级到 1.23.0：

- schema 20 → 21：新增 `llm_usage_events` 表与 `idx_llm_usage_day`、`idx_llm_usage_task`、`idx_llm_usage_model` 索引；旧库启动时幂等补表。
- 版本号 1.23.0；离线更新包 `bbu-fault-platform-1.23.0-offline.tar.gz`。
- 升级前按标准流程备份数据库与运行数据。

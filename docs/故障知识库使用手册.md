# 故障知识库使用手册

## 1. 入口

- 故障问答：`http://<服务器>:8080/#/kb`
- 知识库管理：`http://<服务器>:8080/#/kb/docs?tab=overview`（概览、统计、导入、审核、变更与审计、词典、评测、设置）
- 文档库：`http://<服务器>:8080/#/kb/docs?tab=docs`（只浏览/筛选/分页，不再放导入入口）
- 导入：`http://<服务器>:8080/#/kb/docs?tab=import`（选择文件、查看导入进度和最近任务）
- 知识库操作记录：`http://<服务器>:8080/#/tasks?tab=kb`（检索、修改、导入与审计）
- 单文档详情：`#/kb/docs/{doc_id}`

普通工程师看到脱敏文本；管理员可看原文、编辑、启停、删除和恢复版本。

## 2. 管理员首次启用

1. 确认「系统信息 → 运行时配置 → 故障知识库」的 `kb_enabled` 为开。
2. 进入 `#/kb/docs?tab=import`，点「载入示例」；20 条脱敏示例导入后等待索引状态变为 `ready`。
3. 在 `#/kb` 输入“看门狗复位”，确认返回答案、引用卡片和可点击详情。
4. 需要真实数据时，在「导入」标签选择 CSV/TXT/MD/HTML/DOCX/XLSX/PDF/图片；管理员默认直接生效，也可以选“先进入审核队列”。上传后页面会显示文件级进度，可离开页面让后台任务继续。

## 3. 导入格式

| 格式 | 解析单位 | 备注 |
| --- | --- | --- |
| CSV/TSV | 一行一文档 | 第一列问题、第二列答案；也识别常见列名 |
| TXT/MD/HTML | 一文件一文档 | MD 首个标题作标题；HTML 去脚本/样式 |
| DOCX | 一文件一文档 | 段落、标题样式、表格转文本；嵌入图片只告警 |
| XLSX | 一行一文档 | 读取共享字符串/内联字符串/公式缓存值；多 sheet 逐个处理 |
| 文本型 PDF | 一文件一文档 | 只抽取文本层；扫描件进入人工队列 |
| PNG/JPEG/WebP | 一文件一文档 | 校验格式与尺寸，进入人工转写；不本地 OCR |

单条答案里有多个 `【原因分析】` 时会拆成多个派生案例。例如：

```text
【详细描述】单板反复复位
【原因分析】EPLD 喂狗时序异常
【处理方案】升级 EPLD
【原因分析】电源瞬断导致复位
【处理方案】更换电源模块
```

会生成 2 个案例，分别可检索、可引用。

## 4. 审核

工程师提交的文档进入「待审核」，管理员可：

- 查看案例预览与脱敏原文；
- 修改标题；
- 批准入库（立即重建索引）；
- 退回并填写原因。

图片和扫描 PDF 即使管理员选择“直接生效”也会保留在审核队列，确认人工补录后再批准。

## 5. 问答与引用

- “检索并回答”：先用本地检索找案例，有真实模型时生成总结；无模型时显示“本地检索模式”。
- “仅检索案例”：不调用模型，只显示案例卡片。
- 引用 `K1..K6` 可点击跳到文档详情；详情里可看现象、原因、方案、版本历史。
- 回答里的“降级”标识表示模型不可用或失败，结论来自抽取式摘要，不是模型编造。

## 6. 案例修订与审计

管理员在文档详情页的每个案例右侧可以看到「修订 / 编辑 / 启停」：

- **修订**：打开案例时间线，查看每次变更的 action、操作人、原因、字段级前后值和 SHA256；顶部显示哈希链校验结果。
- **编辑**：必须填写变更原因；保存后追加一条 update 修订并重建索引。
- **启停**：active/disabled/archived 切换同样写入台账。
- **恢复**：在时间线里选择旧修订恢复，会生成一条新的 restore 修订，旧历史不删除。
- 全库变更与审核决策可在 `#/kb/docs?tab=audit` 查看，支持按操作人/动作筛选与 CSV 导出。

## 7. 统计

`#/kb/docs?tab=stats` 提供七组指标：库存、覆盖、使用、审核、变更、导入、索引。支持 7/30/90 天切换和 CSV 导出；库存、覆盖率、索引大小是当前真值，趋势来自查询/修订/审核/导入日志。

## 8. AI 审核

- 导入草稿默认进入 AI 预审队列；案例编辑复审默认关闭，可在运行时配置打开。
- 模型按六维评分（问答匹配、原因完整、方案可执行、实体一致、来源忠实、安全隐私），输出 allowlist 问题与可选字段 patch。
- 无模型、超时、模型失败或 JSON 不合规时转人工（manual），不影响导入；审核结果是独立维度，不覆盖字段完整度 quality。
- 管理员在「审核」页查看待审草稿与审核记录，详情里看六维分数、问题、建议 patch，再人工通过/驳回/采纳。默认不自动发布。

## 9. 维护

- **重建索引**：编辑/启停/删除后自动标脏；管理员也可在文档详情或 `#/kb/docs` 手动触发。
- **版本恢复**：文档详情 → 版本历史 → 恢复；恢复会生成新版本，当前版本保留。
- **停用/删除**：停用不参与检索但保留数据；删除为软删除，版本仍保留。
- **备份**：备份整个 `data/`，其中包含 `data/kb/`；只备份 `bbu.db` 会丢失附件和索引文件。

## 10. 常见问题

**导入后没有结果**

先看 `#/kb/docs` 顶部索引状态；等待 `ready`，或点“重建索引”。如果文档在“待审核”，管理员批准后才进入索引。

**图片/扫描 PDF 显示待审核**

当前不内置 OCR/视觉模型，这是预期行为；请在审核弹窗中人工补录现象、原因和方案后批准。

**回答显示降级**

未配置真实模型，或模型调用失败。检索结果仍然有效；配置模型后重试，或使用“仅检索案例”。

**工程师看不到原文**

设计如此：普通用户只使用脱敏文本；管理员在详情页的“编辑与原文”区可查看原文。

**CSV 中文乱码或列不识别**

文件应为 UTF-8/GBK/GB18030；列名可用 `question/answer`、`问题/答案`、`title/content`。复杂多行答案请用标准 CSV 引号包裹。

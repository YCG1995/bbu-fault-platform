# BBU 故障诊断平台 1.29.0 版本说明

发布日期：2026-11-27

## 主题

本版实现“语义在服务端、传输在浏览器”的浏览器代理模型：模型请求由服务端构造，浏览器只执行 fetch 并回传原始响应。目标版本 1.29.0，数据库 schema 升级到 23。

### 1. 浏览器代理执行

- 新增 `bbu/relay.py`：窗口注册/心跳/租约、单用户窗口上限与最旧窗口顶替、长轮询领取、认领/执行超时、掉线清理、用户登出清队列、重复回传与跨用户检测、回传体上限。
- 模型 `extra.transport` 支持 `server`（默认）与 `browser`；仅 `openai` / `anthropic` 协议可设为浏览器代理。
- 服务端只负责构造请求、解析响应、Schema 校验、重试、熔断与用量统计；浏览器不构造 prompt、不改写模型输出。
- 同一优先级内服务端模型排在浏览器模型之前；浏览器窗口不在线或角色不允许时直接跳过，不写端点故障计数，约 10 秒内回退到服务端模型。
- 浏览器模型测试按钮改为“浏览器内自检”，通过 `POST /api/models/{id}/relay-test` 后台提交并在浏览器领取执行。

### 2. Key 与出站安全

- `RelaySpec` 将 `Authorization` / `x-api-key` / `api-key` 从普通 headers 分离到 `auth`；Key 只允许出现在单次 `GET /api/relay/calls` 响应中。
- 服务端在调用 payload 写出后立即 `consume_auth()` 擦除内存中的 Key；重复领取返回 409，不会再次下发。
- 审计只记录模型、调用、用途、字节数、延迟和错误 kind，不记录 prompt、Key 或响应正文。
- 服务端与浏览器双层校验目标 URL：拒绝非 http(s)、带用户名密码、localhost、127/8、`::1`、169.254.*、`fe80::/10`；默认只允许 HTTPS，`relay_allow_insecure_http=true` 时才允许内网 HTTP。
- 平台 CSP 的 `connect-src` 从仅 `'self'` 放宽为 `'self' https: http:`，以允许浏览器从平台页面直接访问已配置的模型网关；`script-src` 仍为 `'self'`。

### 3. 新增接口

- `GET /api/relay/status`：登录、免 CSRF、心跳并返回窗口/在线模型/轮询间隔。
- `GET /api/relay/calls`：登录、免 CSRF、长轮询；204 表示暂无任务，200 返回单次调用（含 `auth.value`）。
- `POST /api/relay/calls/{call_id}/result`：登录 + CSRF；超限 413、重复 409、过期 410、跨用户 403 并审计。
- `POST /api/relay/release`：`sendBeacon` 使用、免 CSRF，仅释放当前用户窗口。
- `POST /api/models/{id}/relay-test`、`GET /api/models/{id}/relay-test/{test_id}`：管理员浏览器内自检。

REST 路由总数由 162 增至 168。

### 4. 前端

- 新增常驻 `web/assets/js/relay.js`：5 秒状态心跳、独立长轮询、`AbortController` 执行超时、字节预检、指数退避、`pagehide` 释放、浏览器侧 URL/HTTPS 复检。
- 顶栏新增 `#relay-pill` 徽标，点击打开免登录 `/relay-check.html` 自检页。
- 自检页区分网络/代理不可达、CORS 拒绝、认证失败、混合内容与私网 PNA；导出的报告不含 Key、请求头、响应正文或完整 Base URL。
- 管理端模型表新增“执行位置”列、浏览器代理复选框、单窗口并发/认领超时/执行超时/允许角色；普通用户不再看到完整 Base URL 与 Key 掩码。

### 5. 用量与兼容

- `llm_usage_events` 新增 `transport TEXT NOT NULL DEFAULT 'server'`；`init_schema()` 使用按列存在性判断的幂等 `ALTER TABLE` 迁移，旧库可直接升级。
- 用量总览新增 `browser_calls` 与按模型的 `transports`；任务明细同步展示浏览器调用数。
- `transport=server` 的模型行为、既有 162 条接口与诊断/工坊/助手链路保持不变。
- 回滚：`relay_enabled=false` 一键关闭；browser 模型自动不可用并被跳过；schema 23 的列对旧版本无影响。

## 新增/调整配置

| 配置 | 默认 | 说明 |
|---|---|---|
| `relay_enabled` | true | 启用浏览器代理模型 |
| `relay_lease_ttl_sec` | 120 | 浏览器窗口租约 TTL（秒） |
| `relay_status_poll_sec` | 5 | 浏览器心跳/状态轮询间隔（秒） |
| `relay_max_windows_per_user` | 2 | 单用户浏览器窗口上限 |
| `relay_max_response_bytes` | 1048576 | 浏览器回传体上限（字节） |
| `relay_allow_insecure_http` | false | 允许浏览器访问内网 HTTP 模型 |
| `relay_claim_timeout_sec` | 10 | 浏览器认领超时（秒） |
| `relay_exec_timeout_sec` | 90 | 浏览器执行超时（秒） |

模型级字段：`extra.transport`、`extra.browser_relay.max_concurrent`（1–4）、`claim_timeout_sec`（5–60）、`exec_timeout_sec`（30–120）、`allow_roles`（engineer/reviewer/admin，空=不限）。

## 升级

1. 备份 `data/` 与当前安装目录。
2. 解压 1.29.0 离线包，执行 `sudo bash bbu-fault-platform/deploy/install_offline.sh --port 8080`。
3. 启动后 `init_schema()` 自动补 `transport` 列；管理端“系统信息”应显示 schema 23、版本 1.29.0。
4. 浏览器代理需在模型配置中勾选“浏览器代理执行”，保存后由使用页面常驻领取；无在线页面时自动回退服务端模型。

浏览器代理自检

这个页面不需要登录，也不会调用平台业务接口。它只从当前浏览器直接访问你填写的模型网关，用来区分 “网络/代理不可达”和“网关拒绝 CORS”两种现场问题。Key 只存在本页内存，不会写入报告、日志或浏览器存储。

仅用于本页发起一次测试请求；不写入报告，不保存到 localStorage。
填写网关地址后开始自检。建议同事先在浏览器里直接打开模型网关的 /models 地址确认代理是否生效。
现场判定口径：
1. 网络不可达：连 no-cors 探针都失败，通常是系统代理、PAC、证书、防火墙或 DNS 问题。
2. CORS 拒绝：网络探针成功，但带认证头的请求被浏览器拦截；需要网关允许平台 Origin 与预检头。
3. 认证失败：请求到达网关但返回 401/403；检查 Key、认证样式和模型权限。
4. 混合内容：平台是 HTTPS 而网关是 HTTP 时浏览器会直接阻断；需要网关 HTTPS 或把平台部署在同一 HTTP 内网环境。
